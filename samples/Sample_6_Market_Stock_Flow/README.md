# Sample 6: 株券流体システム (Stock Flow Mode) README

本サンプルは、株式市場の取引ネットワークから**「株券の移転と評価額の変動」**のみを抽出し、貸借（B/S）が完璧に一致した閉じた物理・数理システムとしてモデル化したものです。

---

## 1. エグゼクティブ・サマリー（結論）

* **物理的・会計的結論**: 
  本システムは、株式市場における「株券（アセット）」という富の保存則を厳密に成立させています。初期状態（Day 0）の丸め誤差を $0.03$ の精度で微調整し、仕訳を Pruning（剪定）した結果、全期間を通じて財務諸表の不一致が $0.00$（**`✅ BALANCED`**）となる完全な数理的整合性を達成しました。
* **ビジネス上の意義**: 
  市場全体の流動性供給や、「誰がどの銘柄の株券（価値）をどれだけ吸い込んでいるか」という**アセットの偏りと蓄積（ポートフォリオの偏在化）**を可視化・追跡します。

---

## 2. モデル構築の仕組み (Duality & Pruning)

原本となる取引仕訳（`Dummy_Market_Stream_Z_Raw.csv`）から、以下のルールに基づいて「株券（Stock）の動き」だけを剪定・再構成しています。

1. **取引データの抽出**:
   * アセットタイプが株式（`STOCK_001`〜`STOCK_005`）の取引のみを抽出。
   * 取引金額（`Transaction_Amount`）は、物理的な価値の移動を反映するため、**「取引数量 × 取引価格」**として算出します。
   * ノードの複雑化を防ぐため、サフィックス（`_Stock` や `_Issuer`）を除去し、`USR_001` や `STK_001` に表記を統一。
2. **初期状態（Day 0）の貸借一致**:
   * 資産側：各ユーザーの株券保有評価額の合計（`USR_001`〜`USR_010`）
   * 負債側：各銘柄の発行済総額（`STK_001`〜`STK_005`）
   * 上記の両者が完全に一致するよう、四捨五入の端数差分（`0.03`）を `USR_001` の初期値で吸収・調整してスタートしています。

---

## 3. TLU数理指標の会計ドメイン翻訳 (Rosetta Stone)

TLUの物理・数理フィルターが検出する各指標は、株式システムにおいて以下のような実務的な意味に翻訳されます。

| TLU物理指標 | 会計・ビジネスドメインでの実務的意味 |
| :--- | :--- |
| **Viscosity（粘性）** | **市場の流動性の重さ（取引の停滞・塩漬け状態）**<br>粘性が高い状態は、プレイヤーが株券を手放さず、売買が停滞していることを示します。低い状態は、HFTなどにより高速で株式が回転している健全な流動性を意味します。 |
| **Structural Stiffness（構造剛性）** | **アセット（株券）の固定化・ポートフォリオ偏在度**<br>剛性が高い（Stiff）と、特定の銘柄や株主に株式が吸い寄せられて固定化し、外部ショックによるリバランスが困難になっている（柔軟性がない）状態を指します。 |
| **Entropy（エントロピー）** | **株式保有の分散度**<br>エントロピーの急激な低下は、特定のプレイヤーへの株式集中（敵対的買収、あるいは一部プレイヤーへのアセット集中によるシステム歪みの増大）を警告します。 |
| **LQR (制御理論) の感度** | **歪みを解消するための「ツボ（介入点）」**<br>どの銘柄（`STK`）の需給を刺激すれば、システム全体の歪みを最小のコストで解消できるかという、マーケットメイクの最適制御ポリシーを示します。 |

### 熱力学的仕事（Work）と熱（Heat）の定義
* **Work（仕事 / `thermo_work_labels`）**: `USR_001`〜`USR_010`（一般ユーザー群）
  * ユーザーの元に蓄積される「保有株式の評価価値（実体的な富の蓄積）」を指します。
* **Heat（熱 / `thermo_heat_labels`）**: `STK_001`〜`STK_005`（各株式の発行体）
  * システムを駆動するための媒介物であり、発行体が背負う「資本調達コスト（株式の発行高）」を熱的な負荷として扱います。

---

## 4. 時系列での挙動 (Cinematic Sequence)

1. **初期状態（Day 0）**: 
   各ユーザーが手持ちの株式評価額をアセットとして持ち、対向として各発行体（STK）が同額の発行高（Liability）を背負ってバランスした静的な状態でスタートします。
2. **取引の活発化と熱の発生**: 
   取引が始まると、ユーザー間で株券が移動し、その時々の「時価（Price）」で評価額が変動します。
3. **外部との資本取引**: 
   外部（Outside）からの資金流入は `ACC_Input_From_Outside` （純資産 / Equity）に直接加算され、P/Lを一切通らずにB/Sの「純資産」を成長させます（資本取引）。一方、外部への流出は `ACC_Output_To_Outside`（収益）としてマップされ、P/Lを経由してシステムを循環します。

---

## 5. モデルの前提と限界（反証可能性）

* **モデルの限界**: 
  本モデルは「株券の所有権と時価評価額」の移動のみを切り出したクローズド・システムです。
* **反証的注意**: 
  取引の裏で支払われた「現金（Cash）の裏付け」や、ユーザー個々の「現金不足による決済不能リスク」は本システム上では見えません。株価変動による評価額の変化が、そのまま物理的な「質量移動」として表現されるため、現金の支払準備金などの制約を評価する際は、必ず対となる **`Sample_7_Market_Cash_Flow` (Cash Flow Mode)** と併せて実査する必要があります。
