# Sample 12: ERP Dynamic Thermodynamic Cost Allocation (T-ABC)

[日本語版ドキュメントはこちら](../../docs/ja/samples/Sample_12_ERP_TABC.md) / [English Documentation](../../docs/samples/Sample_12_ERP_TABC.md)

## Summary
This sample environment demonstrates Dynamic T-ABC allocation where irreversible process waste heat ($\alpha(t)$) is dynamically computed from activity volatility and isolated as a period expense.

- **Status:** `NORMAL (Tier 1)`
- **Pathology:** Yin-Yang Balance & Waste Expulsion (陰陽平衡・邪気排出)
- **Primary Observation:** Dynamically isolates $60.58k (18.6%) of process waste from product inventory costs.

For detailed analysis and diagnosis, please refer to the documentation linked above.
