# TLU Diagnostic Manual - Appendix A: Macro-Forensic Anomaly Detection

**Status:** Official Sub-Manual (Revised based on Empirical ML Analysis: 2026-05)
**Purpose:** 本マニュアルは、25年間（2000-2024）の実体経済プロキシーデータを用いたランダムフォレスト（Random Forest）解析の逆算結果に基づき、実社会のマクロ経済・システミックリスクを診断する際の「最優先検査項目（Priority Inspection Items）」を再定義するものである。

従来のマニュアル（Tier 1〜5）が「自由エネルギー（F）」や「最適制御コスト（LQR）」の理論的異常を重視していたのに対し、本サブマニュアルは**「現実の市場暴落（アノマリー）を最も強く予測・説明できる実証的な物理指標」**を上位から順に評価するための実戦的プロトコルを提供する。

---

## 🔍 実証的優先検査項目（Top 5 Indicators for Macro Anomalies）

機械学習による重要度（Feature Importance）分析の結果、以下の5つの指標が、システミック・クラッシュ（ITバブル崩壊、リーマン・ショック、コロナ・ショック、インフレ熱死など）を検知するための最も強力なシグナルであることが証明された。メタ診断医は、異常検知の際、必ず以下の順序で数値を検証しなければならない。

### 🥇 1. マクロ・エントロピー爆発（Macro Entropy $S$）
*   **ML Importance Rank:** #1
*   **診断基準:** システム全体の無秩序さ、およびセクター間の「摩擦・引き裂き」の総量。
*   **アノマリーの兆候:** 
    *   **極端なプラス値:** 「ボルマゲドン（2018）」や「高金利下の熱死（2023）」のように、システム内部でセクターが全く異なる方向へ暴走し、構造が物理的に引き裂かれている状態（致命的な摩擦）。
    *   **極端なマイナス値:** 「バブルのピーク」や「パニックの瞬間」において、市場全体が一方向に完全に同期（強制的な相関）している状態。

### 🥈 2. 運動学的・波及リップル効果（Kinematic Ripple Effect / `fk_total_ripple`）
*   **ML Importance Rank:** #2
*   **診断基準:** ある一つのノード（セクター）に発生した運動学的ショック（加速度）が、剛性行列（Stiffness Matrix）を通じて、システム全体にどれだけの「波紋（Ripple）」を広げたかを示す感度指標。
*   **アノマリーの兆候:** 平常時は局所的なショックで収まるが、クラッシュの瞬間にはこの数値が異常なスパイクを見せる。「1つの銀行の破綻」が「全システムの加速度」を歪める状態（連鎖倒産・システミックリスクの可視化）。

### 🥉 3. KLダイバージェンスの漂流（KL Divergence Drift）
*   **ML Importance Rank:** #3
*   **診断基準:** 情報幾何学的な指標。現在のシステムの状態確率分布が、基準となる分布（あるいは過去の平衡状態）からどれだけ「予測不可能な方向へ漂流（Drift）」しているかを示す。
*   **アノマリーの兆候:** 自由エネルギー（F）が枯渇する数ヶ月前から、システムの確率分布が静かに歪み始める（先行指標としての価値が極めて高い）。

### 🏅 4. 自由エネルギーの枯渇（Free Energy $F$）
*   **ML Importance Rank:** #4
*   **診断基準:** システムが現在の構造を維持し、外部環境の変化に抗うために残されている「余力（スタミナ）」。
*   **アノマリーの兆候:** エントロピー爆発と同時に、F が極端なマイナス（枯渇状態）に陥った場合、そのシステムは自律的な回復が不可能であり、外部からの強力な介入（例：中央銀行のQEや利下げ）がなければ「熱死」する。

### 🏅 5. ネットワーク・エッジ応力の喪失（Network Edge Stress）
*   **ML Importance Rank:** #5
*   **診断基準:** セクター同士を繋ぐ「配管（関係性）」にどれほどのテンション（応力）がかかっているか。
*   **アノマリーの兆候:** **「応力のゼロ化（Stress = 0.00）」**。平常時は資金が循環するため応力が発生するが、リーマン・ショックや9.11など、システムが死の淵に立つと循環が完全に停止（血栓化・パニック売り）し、応力が突如として消失する。

## ⚠️ 特別診断ルール：動粘度（Viscosity）による歴史的進化の判定

現代（2015年以降）のマクロ経済を診断する際、メタ診断医は必ず「動粘度（C）」の絶対値を評価し、クラッシュの「質」を分類しなければならない。

*   **旧世代クラッシュ（Viscosity > 50）：** 人間の手動取引パニックによる「血栓症」。流動性が枯渇し、システムがドロドロに詰まった状態（例：9.11、リーマン・ショック）。
*   **新世代クラッシュ（Viscosity < 20）：** アルゴリズムと高頻度取引（HFT）による「超流動クラッシュ」。摩擦ゼロの氷の上を巨大な質量が暴走し、システムが遠心力で引き裂かれる状態（例：コロナ・ショック、2022年のインフレ熱死）。現代のクラッシュは、粘度が高まることなく一瞬でエネルギー（F）だけを奪い去る点に最大の脅威がある。
