# Sample 12: ERP 熱力学配賦モデル (Dynamic T-ABC Allocation)

## 概要
本サンプル環境は、TLU の熱力学・動的ボラティリティモデルを応用した **「動的 T-ABC（Thermodynamic Activity-Based Costing）配賦モデル」** です。
人間による手動の固定値を完全に排除し、現場の日次活動ゆらぎ（ボラティリティ $CV$）から自然発生した不可逆摩擦熱（散逸エントロピー $\alpha(t)$）を自律検知し、製品原価から物理的に独立隔離します。

---

## 物理・数学的シグナルと特徴
* **動的組織摩擦ロスの自律分離 ($\alpha(t)$)**:
  月ごとの活動ゆらぎに応じ、不可逆摩擦熱（年間 **$60,580.00 / 18.6\%$**）が自動算出されて「組織摩擦ロス（期間費用）」として製品原価から隔離されます。
* **純粋実効製造原価の帰属**:
  製品へ配賦される実効間接費は **$265,268.45 (81.4%)** に抑えられ、製品A ($135.6k / 51.1\%$) および製品B ($129.7k / 48.9\%$) に純粋な製造実効原価のみが帰属します。
* **高流動な熱力学平衡 ($S = 3.1100$)**:
  組織の無駄熱を排出しつつ、高い情報自由度と動的応答を達成します。

---

## 東洋医学的所見
* **病態:** **「陰陽平衡・無駄熱（邪気）の自律排出」の相**
* **診断:**
  業務プロセスの不効率に伴う邪気（無駄熱）を自律排出し、製品には純粋な精気（実効製造コスト）のみを流す最高の陰陽平衡状態を示します。

* 🎯 **ツボ (Tsubo):** `ACC_Mfg_Overhead_Exp_DPT_Mfg_Support` ($60.58k の動的組織ロス) ── 不効率の大きかった月における段取り替えの平滑化およびプロセスIT化。
* 🤝 **共生的介入:** 摩擦ロスを現場の責任にせず、組織全体のDX・設備投資のROI指標として活用し、経営陣と現場の共生的改善を推進します。
