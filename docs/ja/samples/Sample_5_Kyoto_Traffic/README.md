## 対象道路網：サンプル5（京都市中心部交通流動）

## 0. エグゼクティヴ・サマリー (Executive Summary)

* **総合判定:** 【警告・要改善】主要交差点の車線・容量規制に伴い、周辺道路へ広範に渋滞が飛び火する**「流動デッドロック（グリッドロック）」**が発生し、交通流動が致命的に麻痺しています。
* **総合体質評価（道路網の状態）:** 
  道路網全体の走行総車両数（**「総体積」**）は厳密に維持されていますが、ボトルネック交差点の容量規制により、交通網全体の迂回吸収力（**「流動の自己復元力」**）は完全に崩壊しています。車両のルート選択の自由度（**「空間エントロピー」**）が急落しており、主要幹線道路が慢性的な車両滞留で柔軟性を失う**「流動グリッドロック（剛性ロック）」**が発生しています。
* **要改善点（滞留交差点と調整ポイント）:**
  - **慢性的な滞留（渋滞）の範囲:** 摩擦抵抗上位25%の範囲である **「五条車屋町 (02_GojoKurumayacho)」**、**「五条室町 (03_GojoMuromachi)」**、**「三条車屋町 (17_SanjoKurumayacho)」** の交差点群に深刻な車両ラグ（渋滞）が発生しており、特に **2021-06**（観光ピーク期）および **2021-12** に滞留がピークに達しています。
  - **信号サイクル調整の「ツボ」の範囲:** 調整時の周辺への渋滞波及（二次的ストレス）が最小の範囲（歪みエネルギー下位25%の範囲）である **「四条烏丸 (21_ShijoKarasuma)」**、**「四条新町 (24_ShijoShinmachi)」**、**「二条烏丸 (11_NijoKarasuma)」** の信号青時間制御が、交通網全体を最もスムーズに復元させるための最優先「ツボ（特効調整ポイントの範囲）」となります。
  - **避けるべき介入（禁忌）の範囲:** 逆に周辺道路へ致命的な渋滞ドミノ（反発歪み）を飛び火させる範囲（歪みエネルギー上位25%の範囲）である **「一条堀川 (05_IchijoHorikawa)」**、**「一条車屋町 (07_IchijoKurumayacho)」**、**「五条堀川 (00_GojoHorikawa)」** への無理な規制や車線削減は、交通網全体の完全フリーズを招くため絶対に避けてください（禁忌）。

## 1. 総合判定（警告・要改善）

### 【判定】：要改善（特定交差点の容量規制によるグリッドロック）
![System Stability (還流の安定性/異常同期)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/004_1_2__system_stability.png)

本都市交通システムにおいて、期間別（単月）の通過流量を検証した結果、2021年1月（t=12）を境に主要交差点 **四条烏丸 (21_ShijoKarasuma)** の通過帯幅がほぼ完全に消失している「局所フリーズ」が検出されました。これは道路工事や規制による車線容量の極端な低下が引き金となり、上流の四条室町などの周辺路へバックアップ渋滞がドミノ式に波及した結果、全体の循環動線が停止した交通デッドロック（グリッドロック）が発生していることを証明しています。速やかに信号点灯サイクルおよび車線規制の最適化を行う必要があります。

## 2. 総合体質（道路網の状態）の分析

京都市中心部の「交通流動」を健康状態の見立てに当てはめると、以下のようなシステム的な歪みが生じています。

### ① 総車両数（累積車両ストック推移）
![B/S Cumulative Trend (資産と資本の累積推移)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_0_1__BS_Trend.png)

道路網内の総車両数（質量）は全期間で厳密に保存されており、車両のゴースト消失や外部からの異常な大量ワープ流入はありません。

### ② 交通網復元力（迂回吸収キャパシティ）
![P/L Cumulative Trend (売上と費用の累積バランス)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_0_1__PL_Trend.png)

2021年1月の容量規制以降、一部の主要交差点でのフリーズを他の道路区間が吸収・迂回するだけのポテンシャル（自由エネルギー）が著しく損なわれており、小さな接触事故等の突発ショックに対する耐久力は失われています。

### ③ 流動の複雑性・選択自由度（エントロピーと熱力学的評価）
![T-S Diagram (流動過熱・交通循環サイクル)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/001_1_3__thermodynamics_ts_diagram.png)

温度 $T$（流量ボラティリティ）とエントロピー $S$（ルート選択のランダム性）の関係を示す T-S図において、容量規制開始後、主要交差点のエントロピーが急激に低下し、四条烏丸の温度（ボラティリティ）は `97.15` から `24.25` まで冷え込んでいます。車両の行き先が完全に固定化して流動選択肢が奪われた、冷たく硬直した「熱力学的凝固」の軌道が描かれています。

### ④ 流動グリッドロック（結合剛性行列に対するPCA評価）
![PCA Ratio (しなやかな循環構造（主成分分析）)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_2_2__principal_axes_ratio.png)

結合剛性行列に対する主成分分析（PCA）の結果、規制開始以降、第1主成分（PC1）の累積説明比率が異常な高位で固定される「剛性ロック（動脈硬化）」状態が継続しています。交通ルート全体の柔軟性が奪われ、グリッドロックが交通網全体を物理的・数学的に束縛していることを実証しています。

## 3. 特筆すべき要改善点（滞留交差点とツボ）

本システムが特定した具体的な要改善点、および対策の方針は以下の通りです。

### ⚠️ 慢性的な滞留（肩こり）の特定（局所粘性時系列トレンドのヒートマップ分析）
![Local Viscosity Trend (局所粘性の時系列推移ヒートマップ)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_1_7_1__viscosity_trend.png)

* **滞り（肩こり）の範囲：** 
  交差点ごとの局所粘性（viscosity_C）の時系列推移ヒートマップ（上記）において、五条車屋町（`02_GojoKurumayacho`）や五条室町（`03_GojoMuromachi`）の区間に定常的な高い流動摩擦（粘性）が蓄積しており、特に観光シーズンである6月や12月に激しい滞留がピークに達する様子が直接的に可視化されています。
  粘性の増大（流動摩擦）は、力学的に「状態軌道が特定の空間領域に引き込まれて身動きが取れなくなるアトラクター固着」をもたらします（詳細は相空間軌道 `000_1_8__phase_portrait_3d.png` を参照）。
  実質交差点の粘性分布から、上位25%に属する **「五条車屋町 (02_GojoKurumayacho)」**、**「五条室町 (03_GojoMuromachi)」**、**「三条車屋町 (17_SanjoKurumayacho)」** などの区間に深刻な車両の滞留が発生しています。
  - **`02_GojoKurumayacho`**: 平均粘性 `1387.53`、最も滞る時期は **`2021-06`** です（ピーク値 `1966.25`）。
  - **`03_GojoMuromachi`**: 平均粘性 `1369.88`、最も滞る時期は **`2021-12`** です。
  - **`17_SanjoKurumayacho`**: 平均粘性 `1339.35`、最も滞る時期は **`2021-12`** です。

### 🎯 信号サイクル調整の「ツボ」および避けるべき介入（禁忌）の特定
![Sensitivity Matrix (改善介入の感度・トレードオフ)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/004_2_1__sensitivity_matrix.png)

* **調整の「ツボ」の範囲：** 介入時の周辺渋滞ドミノ（反発ひずみ）が下位25%の範囲に収まる **「四条烏丸 (21_ShijoKarasuma)」**、**「四条新町 (24_ShijoShinmachi)」**、**「二条烏丸 (11_NijoKarasuma)」** です。
  - **改善アドバイス：** ボトルネックの主原因である四条烏丸の信号青時間の最適化（介入感度ゲイン `-5.80`）は、周辺道路網に新たな渋滞を波及させることなく、最小のフリクションで流動循環を回復できる最優先の「ツボ」領域です。
* **避けるべき介入（禁忌）の範囲：** 逆に強い反発歪み（周辺道路への渋滞波及）を飛び火させる範囲である **「一条堀川 (05_IchijoHorikawa)」**、**「一条車屋町 (07_IchijoKurumayacho)」**、**「五条堀川 (00_GojoHorikawa)」** です。
  - **改善アドバイス：** これらの重要流路に対し、迂回路の整備を行わないまま安易な一方通行化などの強引な流入規制を施すことは、周辺の生活道路まで完全にフリーズさせ、最悪の渋滞ドミノを引き起こすため避けるべき「禁忌アクション」となります。

## 4. 診断の限界および反証条件 (Falsifiability)

本数理モデリングに基づく「交差点デッドロック」の診断を無効化（反証）するためには、以下の客観的な道路実態の証拠を提示しなければなりません。

1. **GPS走行ログによる車速の実証:**
   デッドロックが発生しているとされる時間帯において、対象エリア（四条烏丸〜四条室町）を走行した車両の複数プローブデータ（GPS走行生ログ原本）を解析し、平均車速が時速 `25 km/h` 以上の流れるスムーズな通行が維持されていたことが証明された場合。
2. **定点航空撮影による開通確認:**
   2021年1月以降の渋滞ピーク時において、ヘリコプターやドローン等から撮影された道路網全体の高解像度「航空写真・映像原本」を解析し、交差点内にグリッドロック（詰まり）が一切存在せず、路面が完全にクリアな開通状態であったことが目視で証明された場合。
