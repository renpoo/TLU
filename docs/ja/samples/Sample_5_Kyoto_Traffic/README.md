## 0. エグゼクティヴ・サマリー (Executive Summary)

* **総合判定:** 【警告・要対応（気血空転・還流ロック）】 車両の流れが特定の交差点周回ループで空回り（右左折のループ渋滞）しており、市内から外への円滑な車両排出が行われていません。
* **総合体質評価（健康状態）:**
  グリッド全体の総車両数（**「体格」**）は上限値で飽和しており、突発的な事故や車両消失（**「質量欠損」**）は発生していませんが、信号待ちの連鎖による摩擦損失（**「自律神経の異常興奮・温度高騰」**）が深刻です。特定の道路リンクでのみ車両滞留が固着し、しなやかな交通流が失われています（**「動脈硬化」**）。観光ピークへの突入時（12ステップ）および解消時（24ステップ）の瞬間にのみ、急ブレーキの連鎖（**「脈の乱れ」**）が発生しています。
* **要改善点と共生治療:**
  - **肩こり（回収サイトの遅延）:** **`07_RD_Sanjo_Sales`**（三条通・流入）に慢性的な車両滞留（肩こり）が発生し、ボトルネックとなっています。
  - **ツボ（改善ポイント）:** **`03_RD_Kawaramachi_Cash`**（河原町通）と **`01_RD_Karasuma_Receiving`**（烏丸通）が、渋滞のループを最も自然に解きほぐすためのツボです。
  - **禁忌（避けるべき介入）:** 強い反発と周囲の大渋滞を招く **`07_RD_Sanjo_Sales`**（三条通）への強引な物理的通行規制は避けてください。

  グリッド内の総滞留車両数です。車両数は一定値で安定しており、市内で車両の物理的蒸発（事故死や不正消失）は発生していないことを証明しています。

### ② 免疫力 (ショック吸収バッファー)

### ③ 自律神経 (資金の分散多様性)

### ④ 動脈硬化 (取引の固定ロック評価)

## 4. 反証可能性 (Falsifiability)

本診断結果（環状デッドロック）を覆すには、以下の客観的証拠を提示する必要があります：

1. **実車流の目的地通過ログ:**
   渋滞領域を通過した車両がUターンや環状迂回をしておらず、すべて目的地に向かって一方向かつ最短経路で退出したことを証明する、全車両のGPSトラッキング生データ。
2. **交差点の自動排出証明:**
   交差点において右左折のブロッキングが発生せず、信号サイクルごとにすべての車両が次の道路へスムーズに引き渡されていることを示す、交差点カメラの画像解析統計。
