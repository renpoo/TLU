## 0. エグゼクティヴ・サマリー (Executive Summary)

* **総合判定:** 【警告・交通麻痺】京都市内の主要交差点がボトルネックとなり、中心部エリアで抜け出せなくなる**「交通大渋滞（グリッドロック・デッドロック）」**が発生しています。
* **総合体質評価（身体状態）:** 
  当システムは、領域内の総車両数（**「体格・体重」**）は完全に一定で維持されています（車両の幽霊消失＝大出血はゼロ）。しかし、主要交差点の車線閉塞により、車両の動きが局所的にフリーズする**「コールドアイランド（局所的凝固・冷え）」**が発生しています。車両が抜け道を探す自由（**「自律神経」**）が極端に低下し、全域で関節が硬直して動かなくなる**「慢性的な動脈硬化（ルートの硬化固着）」**が引き起こされています。
* **要改善点（肩こりとツボの特筆）:**
  - **肩こり（慢性的な滞り）の範囲:** **「02_GojoKurumayacho」**、**「03_GojoMuromachi」**、**「17_SanjoKurumayacho」**、**「18_SanjoMuromachi」**、**「24_ShijoShinmachi」**、**「11_NijoKarasuma」**、**「15_SanjoHorikawa」** の領域（粘性上位25%の範囲）に深刻な遅延が発生しており、特に **2021-06** 付近に滞りがピークに達する「肩こり（回収サイト等の長期遅延）」状態が見受けられます。
  - **ツボ（最も効果的な改善ポイント）の範囲:** 介入ストレスが最小の範囲（歪みエネルギー下位25%の範囲）である **「21_ShijoKarasuma」**、**「24_ShijoShinmachi」**、**「11_NijoKarasuma」**、**「06_IchijoKarasuma」**、**「22_ShijoKurumayacho」**、**「20_ShijoHorikawa」**、**「01_GojoKarasuma」** が、システムを健全化させるための最優先ツボ（特効穴の範囲）となります。
  - **禁忌（避けるべき介入）の範囲:** 逆に強い反発と破壊を生む範囲（歪みエネルギー上位25%の範囲）である **「05_IchijoHorikawa」**、**「07_IchijoKurumayacho」**、**「00_GojoHorikawa」**、**「09_IchijoShinmachi」**、**「15_SanjoHorikawa」**、**「18_SanjoMuromachi」**、**「08_IchijoMuromachi」** などへの無理な削減や介入は、強烈な痛みと機能麻痺を招くため絶対に避けてください（禁忌）。

## 1. 総合評価および判定

### 【判定】：交通麻痺（四条烏丸閉塞によるドミノ渋滞）
![System Stability (還流の安定性/異常同期)](../../samples/Sample_5_Kyoto_Traffic/readme_plots/004_1_2__system_stability.png)

本診断において、京都市内の中心部交差点25箇所における交通網は、深刻な流動不全（デッドロック）に陥っています。
これは、全体の車両数が急に増えた（過食）からではなく、主要な結節点である「四条烏丸」の流入容量が工事や事故で極端に絞られたことによって、行き場を失った車両が上流（四条室町など）に溢れかえっていることが原因です。この「詰まり」を解消しなければ、交通網全体の機能停止（麻痺）は周辺全域に常態化してしまいます。

（単月の車両残留ストック：ボトルネック制限の開始以降、特定交差点への滞留が極端化しています）

## 2. 総合体質（健康状態）の分析

交通ネットワークの「流動体力」を健康診断の見立てに当てはめると、以下のような重大な循環不全が発生しています。

### ① 「局所的凝固（冷え）」と「コールドアイランド」
四条烏丸交差点の容量制限以降、その地点の交通の活発さ（流量の変動・体温）が平常時の4分の1まで急落し、完全に「凍りついた状態（コールドアイランド）」になっています。

（単月の通過流量推移：四条烏丸に対応するカラー帯幅が2021-01以降ほぼ完全に消失しています）

### ② ルート選択の自由（自律神経）の麻痺
![T-S Diagram (財務過熱・循環サイクル)](../../samples/Sample_5_Kyoto_Traffic/readme_plots/001_1_3__thermodynamics_ts_diagram.png)

上流の四条室町などでは、流出先が塞がれたことで抜け道を選択する余地（自律神経）が失われ、その交差点内で車両が身動きできなくなっています。

### ③ 「動脈硬化」の常態化
![PCA Ratio (しなやかな循環構造（主成分分析）)](../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_2_2__principal_axes_ratio.png)

渋滞が慢性化した後半ステップにおいて、ネットワーク全体の柔軟性が失われ、一部の交差点だけが赤く硬直（動脈硬化）し、交通がしなやかに迂回する力を失っています。

### 🎯 改善のツボ（特効穴）の特定
![Sensitivity Matrix (改善介入の感度・トレードオフ)](../../samples/Sample_5_Kyoto_Traffic/readme_plots/004_2_1__sensitivity_matrix.png)

* **改善のツボ（特効穴）の範囲：** 介入時の反発ストレス（痛み）が下位25%の範囲に収まる **「21_ShijoKarasuma」**、**「24_ShijoShinmachi」**、**「11_NijoKarasuma」**、**「06_IchijoKarasuma」**、**「22_ShijoKurumayacho」**、**「20_ShijoHorikawa」**、**「01_GojoKarasuma」** です。
  - **改善アドバイス：** これらの項目は、組織/システムのしなやかさを壊すことなく、最も痛みの少ない形で免疫力を回復させることができる特効穴（ツボ）の範囲です。優先度順に調整を施すことを推奨します。

### 🚫 避けるべき介入（禁忌）の特定
* **避けるべき介入（禁忌）の範囲：** 介入時の反発ストレスが上位25%の範囲（または調整不能）に属する **「05_IchijoHorikawa」**、**「07_IchijoKurumayacho」**、**「00_GojoHorikawa」**、**「09_IchijoShinmachi」**、**「15_SanjoHorikawa」**、**「18_SanjoMuromachi」**、**「08_IchijoMuromachi」** です。
  - **改善アドバイス：** 目先の改善のためにこれらの項目へ強引な介入を行うことは、システムの基盤結合を破壊し、最も激しい痛みや組織の崩壊を引き起こす致命的な「禁忌アクション」となります。
