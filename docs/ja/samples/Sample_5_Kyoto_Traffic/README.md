## 0. エグゼクティヴ・サマリー (Executive Summary)

* **総合判定:** 【警告・要改善】主要交差点での車線規制や工事（流入制限）に起因する、広域的な**「都市交通デッドロック（グリッドロック渋滞）」**が発生し、交通流が完全にフリーズしています。
* **総合体質評価（身体状態）:** 
  本交通網内の総車両数（ストック総量である**「体格・体重」**）は厳密に一定に保たれています。しかし、規制開始（2021年1月）以降、渋滞を迂回・吸収する余力（**「免疫力・基礎体力」**）が致命的に低下してマイナス領域（熱的死）に達しています。網内の取引摩擦（**「自律神経」**）は限界まで過熱しており、規制開始を境に道路網全体が完全に柔軟性を失う**「動脈硬化（剛性ロック）」**が発生し、周辺の交差点では急減速や急ブレーキの連鎖（**「加減速ショック・脈の乱れ」**）が激しく発振しています。
* **要改善点（肩こりとツボの特筆）:**
  - **肩こり（慢性的な滞り）の範囲:** 粘性上位の交差点群である **五条車屋町 (`02_GojoKurumayacho`)**、**五条室町 (`03_GojoMuromachi`)**、**三条車屋町 (`17_SanjoKurumayacho`)** などに慢性的なボトルネック（ドロドロ血）が発生しており、観光シーズンや期末に滞留のピークを迎えています。
  - **ツボ（最も効果的な改善ポイント）の範囲:** 介入ストレスが最小（歪みエネルギー下位25%の範囲）であり、かつ全体の渋滞解消ゲインが最大の特効穴（ツボ）は **四条烏丸 (`21_ShijoKarasuma`)** です。信号サイクルの調整や誘導規制は、まず四条烏丸へ優先的に施すべきです。
  - **禁忌（避けるべき介入）の範囲:** 逆に周辺に激しい渋滞の飛び火（反発ストレス）を発生させる **一条堀川 (`05_IchijoHorikawa`)**、**一条車屋町 (`07_IchijoKurumayacho`)**、**五条堀川 (`00_GojoHorikawa`)** などへの無理な進入規制や強制調整は、さらなる交通麻痺（激しい痛み）を誘発するため避けてください（禁忌）。

## 1. 総合判定（警告・要改善）

### 【判定】：要改善（主要交差点規制に伴う流動麻痺）
![System Stability (還流の安定性/異常同期)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/004_1_2__system_stability.png)

本システムにおいて、2021-01 (t=12) を境に四条烏丸の通過車両数がほぼ完全に消失（フリーズ）し、それに伴うバックアップ渋滞が網全体にドミノ倒しのように伝播する「グリッドロック」を検知しました。安定性指標（スペクトル半径 $\rho$）は完全に最大値 **`1.0000`** で飽和しており、交通流が外部へ抜けずに内部ループで停滞・空回りしている病的状態を実証しています。四条烏丸の青信号サイクル（流入容量）を最適化し、上流へ波及した渋滞の還流（スペクトル飽和）を解く緊急介入が必要です。

## 2. 総合体質（健康状態）の分析

都市交通の「流動体力」を健康診断の見立てに当てはめると、以下のような重篤な不全が発生しています。

### ① 体格・体重（道路網内の車両総数）
![B/S Cumulative Trend (資産と資本の累積推移)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_0_1__BS_Trend.png)

道路網の中の総車両数（質量・体格）は `10000` 台で厳密に保存されており、幽霊消滅（質量リーク）はありません。

### ② 免疫力・基礎体力（渋滞吸収・迂回余力）
![P/L Cumulative Trend (売上と費用の累積バランス)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_0_1__PL_Trend.png)

規制開始前は十分な迂回容量（免疫力）がありましたが、規制後は渋滞が網全体を占拠したため、事故などの追加ショックを自律吸収する復元余力が完全に底をつき、極端な機能低下（熱的死）に陥っています。

### ③ 自律神経・代謝効率（流動ランダム度と熱力学的評価）
![T-S Diagram (財務過熱・循環サイクル)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/001_1_3__thermodynamics_ts_diagram.png)

規制以降、ドライバーが迂回ルートを自由に選択できる度合い（自律神経・エントロピー）が激減しています。渋滞箇所でのアイドリングや無駄な加減速による摩擦熱（エネルギー浪費）が極大化し、道路網全体の代謝効率は最悪レベルです。

### ④ 「動脈硬化」（交差点間の支配軸固定化）
![PCA Ratio (しなやかな循環構造（主成分分析）)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_2_2__principal_axes_ratio.png)

四条烏丸の車線規制により、車両流動のルートが不自然に固定化され、第一主成分（PC1）の累積説明比率が規制開始以降に急上昇。交通網全体にしなやかさが失われ、完全に硬直した血管（動脈硬化）と化しています。

### ⑤ 脈の乱れと初期波の検知（高階動的ショックの評価）
![3D Jerk](../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_1_9__3d_dynamics_jerk.png)

![3D Snap](../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_1_10__3d_dynamics_snap.png)

* **数学的架け橋 (Mathematical Bridge):**
  道路網内での車両の「急ブレーキ・急加速（Jerk）」および「ブレーキランプの伝播ゆらぎ（Snap）」を可視化しました。規制開始の 2021-01 以降、主要交差点の周辺においてこれらの急激な脈の乱れのインパルス（高次のショック波）が異常に増幅・発振しており、車列が滑らかに流れず、ストップ・アンド・ゴーを激しく繰り返す「交通ノッキング共振」が発生していることを物理的に証明しています。

## 3. 特筆すべき要改善点（肩こりとツボ）

本システムが特定した具体的な要改善点、および対策の方針は以下の通りです。

### ⚠️ 肩こり（慢性的な滞り）の特定（局所粘性時系列トレンドのヒートマップ分析）
![Local Viscosity Trend (局所粘性の時系列推移ヒートマップ)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_1_7_1__viscosity_trend.png)

* **滞り（肩こり）の交差点：** 
  交差点ごとの流動摩擦（粘性）のヒートマップ（上記）から、**五条車屋町 (`02_GojoKurumayacho`)** や **五条室町 (`03_GojoMuromachi`)** などの交差点で慢性的な激しい詰まりが発生しており、観光シーズンや期末にそれがピークに達している「交通肩こり」状態が証明されています。

### 🎯 改善のツボ（特効穴）の特定
![Sensitivity Matrix (改善介入の感度・トレードオフ)](../../../../samples/Sample_5_Kyoto_Traffic/readme_plots/004_2_1__sensitivity_matrix.png)

* **改善のツボ（特効穴）：** 介入歪み（周辺への渋滞の飛び火・痛み）が極小で、全体の渋滞解消感度が最大（`-5.80`）である **四条烏丸 (`21_ShijoKarasuma`)** です。
  - **改善アドバイス：** 四条烏丸の通過容量を少しでも拡大（瀉：青信号の延長等）させれば、余計な摩擦を生むことなく周辺交通網全体のインピーダンス（渋滞抵抗）を指数関数的に低減させ、最も「痛みの少ない」交通流最適化を達成できます。

### 🚫 避けるべき介入（禁忌）の特定
* **避けるべき介入（禁忌）：** 介入歪みが極めて高い **一条堀川 (`05_IchijoHorikawa`)**、**一条車屋町 (`07_IchijoKurumayacho`)**、**五条堀川 (`00_GojoHorikawa`)** などへの無理な進入規制や強制調整です。
  - **改善アドバイス：** 目先の渋滞を逃がすためにこれらの交差点へ強硬な進入禁止や迂回規制を施すことは、交通網全体の基盤トポロジーを破壊し、最も激しい渋滞の飛び火やマヒを引き起こす致命的な「禁忌アクション」となります。

### ⚡ 決済血管の時間的急変（剛性時間差分）の評価
- **剛性時間差分ヒートマップシーケンス (縦一列表示)**:
  - **規制開始 (t=12)**: ![Stiffness Diff t=12](../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_2_4__stiffness_diff.t.00012.png)
  - **渋滞飽和 (t=18)**: ![Stiffness Diff t=18](../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_2_4__stiffness_diff.t.00018.png)
  - **終末閉塞 (t=23)**: ![Stiffness Diff t=23](../../../samples/Sample_5_Kyoto_Traffic/readme_plots/000_2_4__stiffness_diff.t.00023.png)

* **数学的架け橋 (Mathematical Bridge):**
  月次の道路結合剛性の変化差分 $\Delta K_t$ によって、規制開始の t=12 に四条烏丸 $\to$ 四条室町間が硬直（赤：渋滞発生）し、その後時間の経過（t=18, t=23）とともに、周辺の主要バイパス路や並行道路にまで真っ赤な結合硬化（Stiffness Lock）がクモの巣のように波及・恒常化していくプロセスを可視化しました。道路という「血管」が渋滞によってカチカチに硬化し、完全に閉塞していくグリッドロックの推移を証明しています。

## 4. 診断の限界および反証条件 (Falsifiability)

本レポートにおける「交差点規制に伴う都市交通グリッドロック」の病的診断結果を却下（反証）するためには、以下の客観的な物理的原本・第三者証拠を提示しなければなりません。

1. **実車GPSプローブデータの独立整合:**
   グリッドロックが指摘されているエリアを実際に通過した数千台の車両の「GPS位置情報・速度生ログ（プローブデータ）」を解析した結果、四条烏丸交差点を通過する平均車速が規制期間中も時速 30km 以上で一定に保たれており、不連続なフリーズが発生していなかったことが実証された場合。
2. **容量規制工事ログの不一致:**
   2021-01以降に発生したとされる流入容量規制について、京都市または公安委員会の「道路工事許可台帳」「信号サイクル制御記録ログ」の原本と照合した結果、車線幅員減少工事や車線規制、または信号表示パターンの変更自体が物理的に存在しなかったことが証明された場合。
