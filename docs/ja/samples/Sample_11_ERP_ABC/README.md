# Sample 11: ERP 標準活動基準原価計算 (Standard ABC Allocation)

## 概要
本サンプル環境は、製造間接費を複数の独立した活動（Activity Pool: 機械稼働時間 40%、段取り替え回数 35%、品質検査件数 25%）に分割して製品へ分配する **「標準活動基準原価計算 (ABC) モデル」** です。
伝統的配賦で隠蔽されていた製品Bの手間（高頻度な段取り・検査）が適正に可視化されます。

---

## 物理・数学的シグナルと特徴
* **実態に即した配賦比率の復元**:
  製品Aへの配賦が **51.2%**、製品Bへの配賦が **48.8%** となり、ほぼ 1:1 の実態に即した原価構造が復元されます。
* **熱力学エントロピーの上昇 ($S = 3.1100$)**:
  多角的な活動プールによりシステムの情報自由度が復活し、高い機能流動性を達成します。
* **動的波動の捕獲 (エントロピー Skewness: `-2.4916`)**:
  毎月末に複数プールから非同期に配賦が実行されるため、明確な動的パルスが捉えられます。

---

## 東洋医学的所見
* **病態:** **「経絡疎通・動的脈動」の相**
* **診断:**
  全経絡の気血の流動が実態と調和し、製品Bの隠れ赤字が完全に解消された正常な代謝状態を示します。

## 改善のツボと実務アクション
* 🎯 **ツボ (Tsubo):** `ACC_Finished_Goods_DPT_Prod_B` ── 製品Bの段取り（Setup）時間短縮と検査プロセスの自動化。
* 🤝 **共生的介入:** 製品Bに対する特注料金（オプション請求）の適正化および最低受注数量のルール化。
