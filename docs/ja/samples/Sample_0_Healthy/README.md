### 2. 主要な検知結果（マクロ・ミクロ分析）

### 3. フォレンジック・ケーススタディ：異常の追跡と原因究明
ダミーデータに混入したこの「黄色い特異点（異常）」は、TLUの数理解析能力を証明する完璧な事例です。

1. **異常の発生地点の特定:**
   データの軸ラベルを確認すると、この特異点が **2020年第4週（2020-W04）** の **現金勘定（ACC_Cash）** で発生した異常であることが直感的に特定できます。
2. **元のダミー・データの検証:**
   ジャーナルの該当期間を検証すると、第1週〜第3週までの現金流出は毎週わずか $1,000 程度でした。しかし、**2020-W04** に各部門の「給与支払い」と「オフィス家賃」の仕訳が同時に記帳され、一気に **$26,757** もの現金が流出しました。
3. **異常の真実とシステムの学習:**
   これはシステム稼働後「初」となる月末の固定費支払いです。小さな変動しか学習していないTLUにとって、この突如発生した $26,000 超の流出は、過去の軌道から完全に逸脱した「巨大なショック（Z=121.13）」として映りました。重要なのは、翌月にさらに大きな流出があったにもかかわらず、その時の Z-Score は **2.28** と正常範囲に収まった点です。TLUは初回のショックを経験したことで、このシステムには「月に一度、巨大な現金流出の波が来る」という構造的リズムを学習・適応したのです。

**【結論】**
