## 🩺 AIメタ診断 統合レポート（Laboratory Findings）

### 1. 診断サマリー
対象システム（`Sample_0_Healthy`）は構造的に健全であり、数学的にも均衡が保たれています。組織の健全性を脅かすようなシステム全体にわたる不正、横領、または循環取引の証拠は一切ありません。
ビジネスは健全な営業利益を生み出しています。しかし、単一の極めて局所的な統計的異常（ミクロな異常値）が検出されており、これは悪意のある不正ではなく、正常なビジネスプロセスのイベントを示唆しています。

### 2. 主要な検知結果（マクロ・ミクロ分析）
* **診断:** 初期稼働ショック（稼働後初の大型決済イベント）
* **深刻度:** LOW (低) — *正常なビジネス・サイクルの発現*
* **物理的証拠:** 
  **[マクロ分析]** システム全体の指標（質量漏れ率: 0.0、スペクトル半径: 0.0）はすべて完全に正常であり、システム全体が極めて健全であることを証明しています。
  **[ミクロ分析]** しかし、局所的なミクロ分析（Z-Score 3D Surface）において、最大 Z-Score が **121.13**（閾値: 3.0）という巨大な異常値（スパイク）が検出されました。
  ![Micro Z-Score 3D Surface](../../../../samples/Sample_0_Healthy/readme_plots/002_2_2_2__micro_Z_Score_3d_surface.png)
  * **💡 グラフの読み方（マクロとミクロ）:** 
    ミクロ Z-Score 3D Surface を俯瞰すると、地形全体（マクロ）は Z-Score が低く安定した正常な領域（暗い色・平坦な波）として広がっています。その中に、単一の座標（`2020-W04`, `ACC_Cash`）においてのみ、**周囲の地形から突出した鋭いスパイク（針）** が確認できます。これは、特定の時間と特定の勘定科目においてのみ、過去の傾向からは予測不可能な「極度な数値の跳ね上がり」が発生したことを示しています。

### 3. フォレンジック・ケーススタディ：異常の追跡と原因究明
ダミーデータにおいて検出されたこの「鋭いスパイク」は、TLUの異常検知能力の正確さを証明する事例です。なぜ異常値が出たのか、元のダミー・データ（`Dummy_Journal_Stream.csv`）まで遡って検証します。

1. **異常の発生地点の特定:**
   TLUの出力データや3D Surfaceの軸ラベルを確認するだけで、このスパイクが **2020年第4週（2020-W04）** の **現金勘定（ACC_Cash）** で発生した異常であることが直感的に特定できます。
2. **元のダミー・データ（仕訳帳）の検証:**
   `Dummy_Journal_Stream.csv` の該当期間を検証すると、稼働第1週〜第3週までの現金の流出（支払）は毎週わずか $1,000〜$1,600 程度で推移していました。
   しかし、**2020-W04（1月25日）** に、オペレーション部門・営業部門・管理部門の「給与支払い」と「オフィス家賃」の仕訳（`Payroll_Ops`, `Payroll_Sales`, `Payroll_Admin`, `Monthly_Rent`）が同時に記帳され、一気に **$26,757** もの現金が流出しました。
3. **異常の真実とシステムの適応:**
   これは事業稼働後「初」となる月末の固定費支払いです。第1〜3週の「極めて小さな変動」しか学習していないTLUにとって、この突如発生した $26,000 超の現金流出は、過去の傾向から完全に逸脱した「異常なスパイク（Z=121.13）」として検知されました。
   さらに重要なのは、翌月（2020年2月25日の第9週）にさらに大きな $32,897 の現金流出があったにもかかわらず、その時の Z-Score はわずか **2.28** と正常範囲に収まっている点です。TLUは初回のスパイクを経験したことで、このシステムには「月に一度、巨大な現金流出の波が来る」という正常なビジネスサイクル（給与支払いサイクル）を学習・適応したのです。

**【結論】**
このスパイクの出現は「バグ」や「不正」ではありません。システムが、**「稼働後初の未知のイベント（初期給与支払い）を正確に異常として捕捉し、その後そのリズムを正常サイクルとして学習した」**という挙動の証明です。
以後のサンプル（Sample 1〜9）においては、この「初期稼働ショック（単一のスパイク）」を健全なビジネスの「鼓動の始まり」として基準とし、それとは全く異なるパターンで発生する不正や異常との違い（地形の変化）に注目してください。
