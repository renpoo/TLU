  > これは、対象ノードがシステム内のすべての経路に対して無損失でシグナルを送り届ける、完全なアトラクター（同期ループのハブ）と化していることを証明しています。

  さらに、この過同期状態が継続すると、統計モデルはこれをベースラインとして学習してしまい、後半戦になるほど異常を「正常」として不可視化（モデル汚染・茹でガエル現象）します。したがって、本検査においては個別の Z-Score 警告を棄却（トリアージ）し、スペクトル半径の上限飽和（`1.0000`）および BOLD 流量の数値一致という物理・トポロジー指標に基づいて、てんかん発作病理と確定検査を下します。
* **アーティファクト（ノイズ）との区別:**
  fMRI 装置のスキャナー機械振動や、被験者の呼吸・心拍に伴う「周期的アーティファクト」も、脳全体に周期的な同期信号を混入させます。しかし、機械的・生理的ノイズによる同期は、全ノードの振幅と位相が一様に同じ動きをする「均一な同調」となります。
  一方、本アノマリーでは、側頭葉（`03_Temporal_Lobe`）自体の KL Drift が `0.0000` でありながら、それを受信する側（`00_Motor_Cortex` 等）だけに `0.23` 前後の急峻な KL Drift の壁（情報の非対称な伝達）が発生しており、明らかに「非対称な情報伝播を伴う神経ネットワークの動的相互作用」を示しています。よって、機械的ノイズの可能性を棄却し、病的てんかん発作と断定します。

### 6.2. 本検査に対する反証条件 (Falsifiability)

もし「本脳ネットワークの同期現象は病的てんかん発作ではなく、正常な生理的同調（例：瞑想、深い睡眠、または装置ノイズ）である」と反証するためには、当事者は監査人に対し以下の**「データ境界の外側にある客観的物理証拠（原本）」**を提示する必要があります：

1. **臨床脳波（EEG/iEEG）測定生ログ原本の提示:**
   t=30（10:05:00）に対応するタイムスタンプにおいて、被験者に装着された臨床脳波計、または頭蓋内に留置された深部電極（iEEG）の生データにおいて、側頭葉領域から発生する「棘徐波結合（Spike-and-Wave Discharges, 3Hz）」や「高振幅棘波の連続発射」といった典型的なてんかん性異常波形が観察されず、脳波上が正常なアルファ波または低振幅速波のみの健全状態を示していることの物理的証明。
2. **血中抗てんかん薬濃度および代謝生化学スクリーニング原本:**
   発作直後（t=59以降）に採取された被験者の血液生化学検査原本において、血中抗てんかん薬（バルプロ酸、レベチラセタム等）の濃度が有効治療域内に維持されていること、および急性アシドーシス（乳酸値の急激な上昇やpHの低下など、全身性けいれん・発作による無酸素代謝代謝産物）の痕跡が一切認められないことを示す第三者臨床ラボ発行の分析証明原本の提示。
