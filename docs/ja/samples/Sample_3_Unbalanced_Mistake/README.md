# 🔬 メタ検査臨床検査レポート：単発の入力ミス / 経理システム不整合 (Sample 3)

## 1. 検査結論 (Executive Summary)

* **総合判定:** 🟡 **一時的データ不整合 / 経理ヒューマンエラー (Transient Mismatch / Human Error)**
* **重症度:** 🟡 **WARNING (警告・要監視)**
* **概要:** 
  本システムは、売掛金回収仕訳において貸借金額が一致しない「局所的データ不整合（質量欠損）」を発症しています。シミュレーション期間中の累計で **`$1,412.88`** の質量が一時的にシステム外へ流出しました。この差額は仮想のゴミ箱ノード `UNKNOWN_LEAK` へ振り分けられました。
  数理解析結果によると、これは継続的な不正流出ではなく「単発の入力不整合（弾性的ひずみ）」です。最大スペクトル半径は全期間を通じて **`0.00`** です。循環取引などのトポロジーは存在しません。また、不整合によるひずみが発生した直後に、剛性行列が元の健全な状態へ復帰する「自己治癒能力（弾性）」が機能しています。
  従来の Z-Score 監視は、季節変動による売上急増（7月・8月）に対して「偽陽性（過剰検知）」の警告を出しました。一方で、11月の最大不整合（`$906.29`）に対しては取引量に埋没し「偽陰性（見逃し）」を示す死角を有していました。物理保存則（キルヒホッフ残差）およびトポロジーの自己修復性に基づく統合分析により、本件は「単発ミス」と判定されます。

## 3. 根本的な病態生理解説 (Pathophysiology)

* **病態判定:** **一時的入力エラー (Transient Bookkeeping Error)**
* **不整合仕訳の発生機序 (Dummy_Journal_Stream.csv 原本照合):**
  売掛金（`ACC_Accounts_Receivable`）を減少（Credit）させる回収プロセスにおいて、現預金（`ACC_Cash`）への入金額（Debit）と一致しない片面記帳ミスが記録されています。
  具体的には、以下の 4 件（3 タイムステップ）において不整合が発生しています。
  * **2020-02-23 (t=1)**: `E_000484` (売掛金減少 `$513.93` に対し、現金増加が `$347.35`。差額 **`$166.58`** の質量欠損)
  * **2020-03-20 (t=2)**: `E_000771` (売掛金減少 `$571.88` に対し、現金増加が `$231.87`。差額 **`$340.01`** の質量欠損)
  * **2020-11-02 (t=10)**: `E_002988` (売掛金減少 `$950.16` に対し、現金増加が `$171.60`。差額 **`$778.56`** の質量欠損)
  * **2020-11-27 (t=10)**: `E_003179` (売掛金減少 `$734.53` に対し、現金増加が `$606.80`。差額 **`$127.73`** の質量欠損。11月の不整合合計は **`$906.29`**)
  * **累計不整合額**: **`$1,412.88`**
  物理数学エンジンは力学的閉鎖系を保つために、一時的な漏洩ノード `UNKNOWN_LEAK` にこの差額を割り振ります。しかし、結合が持続・強化されることはありません。システムが持つ「自己治癒性」によって元の健康状態へ復元されます。

## 6. アラート & 反証可能性

### 6.1. 統計的偽陽性と偽陰性のトリアージ (Triaging Statistical Anomalies)

* **トリアージ判定:** 7月および8月に発生した Z-Score の警告スパイクは、「正常活動に伴う統計的偽陽性」として棄却します。深層のキルヒホッフ物理残差がその期間中に `0.00` であり、トポロジー構造も安定しているためです。
* **偽陰性の克服:** Z-Score が沈黙した11月には、キルヒホッフ残差が **`906.29`** の異常値を示しています。そのため統計モデルの正常判定を棄却し、「物理不整合」が発生していると判定します。剛性行列が一時的なひずみの後に自己修復しているため、「単発のエラー」と判断します。

### 6.2. 本検査に対する反証条件 (Falsifiability)

本レポートの「偶発的な記帳ミス」という判定を覆し、「組織的資金着服（横領）」であると反証するためには、以下の証拠の提示が必要です：

1. **金融機関の送金指図書原本:** 差額（計 `$1,412.88`）に対応する日付において、法人の正規口座から第三者の未開示口座へ同額の送金が行われたことを示す「銀行口座取引明細書原本」または「送金受領書原本」。
2. **物理的配送ログ of 不一致:** 取引先に関して、物流業者の「出荷・検収伝票原本」を照合します。帳簿上の減少額と、実際に納品された商品の数量・金額との間に不一致が存在することの提示。
