## 0. エグゼクティヴ・サマリー (Executive Summary)

* **総合判定:** 【警告・単発の記帳ミス】売掛金の回収処理において、左右の金額が一致しない**「単純な入力ミス（経理エラー）」**が発生しています。
* **総合体質評価（身体状態）:** 
  当組織は、基礎的な「体重（資産額）」は安定しており、外部ショックに耐えうる「免疫力（基礎体力）」も健全です。不整合が発生した月（2月、3月、11月）には一時的な**「出血（入力不整合）」**が見られますが、時間が経てば自律的に元の健康な状態へ回復する**「高い自己治癒力（弾性）」**を持っています。慢性的な関節の硬さ（**「動脈硬化」**）は発生していません。
* **要改善点（肩こりとツボの特筆）:**
  - **肩こり（慢性的な滞り）の範囲:** **「04_ACC_Inventory」**、**「03_ACC_Cash」**、**「07_ACC_Sales_Revenue」** の領域（粘性上位25%の範囲）に深刻な遅延が発生しており、特に **2020-12** 付近に滞りがピークに達する「肩こり（回収サイト等の長期遅延）」状態が見受けられます。
  - **ツボ（最も効果的な改善ポイント）の範囲:** 介入ストレスが最小の範囲（歪みエネルギー下位25%の範囲）である **「02_ACC_COGS」**、**「04_ACC_Inventory」**、**「01_ACC_Accounts_Receivable」** が、システムを健全化させるための最優先ツボ（特効穴の範囲）となります。
  - **禁忌（避けるべき介入）の範囲:** 逆に強い反発と破壊を生む範囲（歪みエネルギー上位25%の範囲）である **「09_UNKNOWN_LEAK」**、**「07_ACC_Sales_Revenue」**、**「10_ACC_Equity_Capital」** などへの無理な削減や介入は、強烈な痛みと機能麻痺を招くため絶対に避けてください（禁忌）。

### 【判定】：警告（単発の入力エラーと自己修復）
![System Stability (還流の安定性/異常同期)](../../samples/Sample_3_Unbalanced_Mistake/readme_plots/004_1_2__system_stability.png)

本診断において、当組織は売掛金の回収仕訳において、入力した金額が一致しないデータ不整合（片面記帳ミス）を一時的に起こしています。
しかし、これは意図的な横領（Sample 2）のような継続的な資金流出（大出血）ではなく、一時的に組織が耐えられる「軽い打撲（弾性ひずみ）」のようなものです。不整合があった直後には、システム自身が本来の正常な形にピタッと復元しており、慢性的な問題にはなっていません。当該月の仕訳原本を確認し、金額の入力漏れを修正すれば、すぐに完全な健康体へ戻ります。

（単月の資金推移：不整合が発生した月において、一時的で局所的な歪みが検出されています）

## 2. 総合体質（健康状態）の分析

組織の「財務体力」を健康診断の見立てに当てはめると、以下のような健全な回復力を持っています。

### ① 一時的で単発の「出血」（入力ミス）
2月、3月、11月にデータにズレが生じていますが、それは一時的なものです。長引いて組織力を削るものではありません。

（保存残差の推移：入力エラーが発生した月のみ鋭いスパイクを記録し、その後は完全に修復されています）

### ② 高い「自己治癒力」（システムのしなやかさ）
![P/L Cumulative Trend (売上と費用の累積バランス)](../../samples/Sample_3_Unbalanced_Mistake/readme_plots/000_0_1__PL_Trend.png)

不整合が発生したステップの直後には、取引構造が柔軟に自己修復されています。特定のハブが硬化し続ける「動脈硬化」のような病的固着は一切検出されていません。

### ③ 健全な「免疫力・基礎体力」
![P/L Cumulative Trend (売上と費用の累積バランス)](../../samples/Sample_3_Unbalanced_Mistake/readme_plots/000_0_1__PL_Trend.png)

## 3. 特筆すべき要改善点（肩こりとツボ）

本システムが特定した具体的な要改善点、および対策の方針は以下の通りです。

### ⚠️ 肩こり（慢性的な滞り）の特定
![3D Phase Portrait (状態空間の軌道と固着)](../../samples/Sample_3_Unbalanced_Mistake/readme_plots/000_1_8__phase_portrait_3d.png)

* **滞り（肩こり）の範囲：** 実質ノード全体の粘性分布から、上位25%に属する **「04_ACC_Inventory」**、**「03_ACC_Cash」**、**「07_ACC_Sales_Revenue」** の範囲に慢性的な滞留（ドロドロ血）が発生しています。
  - **`04_ACC_Inventory`**: 最も滞る時期は **`2020-12`** に記録されており、代謝遅延による慢性的な経営/生体機能の圧迫を引き起こしています。
  - **`03_ACC_Cash`**: 最も滞る時期は **`2020-06`** に記録されており、代謝遅延による慢性的な経営/生体機能の圧迫を引き起こしています。
  - **`07_ACC_Sales_Revenue`**: 最も滞る時期は **`2020-12`** に記録されており、代謝遅延による慢性的な経営/生体機能の圧迫を引き起こしています。

### 🎯 改善のツボ（特効穴）の特定
![Sensitivity Matrix (改善介入の感度・トレードオフ)](../../samples/Sample_3_Unbalanced_Mistake/readme_plots/004_2_1__sensitivity_matrix.png)

* **改善のツボ（特効穴）の範囲：** 介入時の反発ストレス（痛み）が下位25%の範囲に収まる **「02_ACC_COGS」**、**「04_ACC_Inventory」**、**「01_ACC_Accounts_Receivable」** です。
  - **改善アドバイス：** これらの項目は、組織/システムのしなやかさを壊すことなく、最も痛みの少ない形で免疫力を回復させることができる特効穴（ツボ）の範囲です。優先度順に調整を施すことを推奨します。

### 🚫 避けるべき介入（禁忌）の特定
* **避けるべき介入（禁忌）の範囲：** 介入時の反発ストレスが上位25%の範囲（または調整不能）に属する **「09_UNKNOWN_LEAK」**、**「07_ACC_Sales_Revenue」**、**「10_ACC_Equity_Capital」** です。
  - **改善アドバイス：** 目先の改善のためにこれらの項目へ強引な介入を行うことは、システムの基盤結合を破壊し、最も激しい痛みや組織の崩壊を引き起こす致命的な「禁忌アクション」となります。
