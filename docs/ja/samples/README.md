# 🔬 TLU 物理数学エンジン：数理解析ガイド＆検証サンプル総合目次 (Universal Forensic Cross-Verification Registry)

Tensor-Link Utility (TLU) は、物理数学エンジンです。複式簿記、都市交通、金融市場、脳fMRIデータを物理法則に基づいて統一的に検査します。

本書は、各種数理解析ガイドおよび10の検証サンプルの比較検証ドキュメント兼総合目次です。システム内には病的異常が潜むことがあります。病的異常はエネルギーを浪費します。構造的硬直を招きます。あるいは質量保存を破綻させます。それにより、システムは熱的死に至ります。本書では、このプロセスを解説します。東洋医学の臨床メタファーを交えて体系化しています。

## 🧠 病態分類別の比較検証・機序分析 (Pathological Cross-Verification)

TLUは「ドメインを超え、異なる事象が同一の物理方程式上で同一の病理署名として解読される」ことを実証します。4つの病態グループの共通機序を検証します。

### 🔴 1. 質量欠損・虚血病態 (Mass Leak / Ischemia)

* **対象:** [Sample 2 (資金横領)](./Sample_2_Embezzlement_Leak/README.md), [Sample 8 (脳梗塞)](./Sample_8_fMRI_Stroke/README.md)
* **共通の物理シグニチャ:** **キルヒホッフ保存則の不整合、およびトポロジー剛性のフリーズ（Rigid Lock）**
* **機序のクロス検証:**
  * **金融（Sample 2）:** 売掛金の回収時に現預金へ格納されません。ダミーノード `UNKNOWN_LEAK` を経由して系外へ資金が吸い出されます。この結果、マクロ保存残差が最大 **`364.53`** 発生しました。累計で **`$1,353.48`** の資金（質量）が失われました。流動性が喪失します。それにより、勘定間の結合剛性が極限まで凝固します。後半の取引変動に対して壊滅的な共振を引き起こします。
  * **生体脳（Sample 8）:** TR=150 (`t=30`) 以降、運動野（`Motor_Cortex`）への血液（BOLD信号の質量）供給が 95% 遮断されます。この領域は局所的に虚血状態となります。活動質量の急減により、運動野周辺の機能的結合剛性が異常凝固（Rigid Lock）します。運動野のエントロピーが垂直落下します。
  * **結論:** 資金横領と脳梗塞は同型の病態です。ネットワークから活動質量が失われます。サスペンションが消滅し、構造が硬直化します。

### ⚖️ 2. 過同期・還流病態 (Hyper-synchronization / Recirculation)

* **対象:** [Sample 1 (循環取引)](./Sample_1_Wash_Trade/README.md), [Sample 5 (京都交通渋滞)](./Sample_5_Kyoto_Traffic/README.md), [Sample 9 (てんかん発作)](./Sample_9_fMRI_Seizure/README.md)
* **共通の物理シグニチャ:** **スペクトル半径（$\rho$）の上限飽和、および自由エネルギーの摩擦消費（エントロピー損失）**
* **機序のクロス検証:**
  * **循環仕訳（Sample 1）:** 実体のない往復取引により、スペクトル半径が警戒域の **`0.75`** まで急上昇します。内部活動量（内部エネルギー $U$）は見かけ上成長します。しかし、そのエネルギーは往復の摩擦熱（エントロピー $T \times S$）として浪費されます。自由エネルギー $F = U - TS$ を損ないます。
  * **都市交通（Sample 5）:** 四条烏丸周辺の容量制限（ボトルネック）によりスペクトル半径が境界上限値の **`1.00`** に飽和します。マクロエントロピー $S$ は `40.69` から **`39.18`** へと低下します。流動阻害による摩擦熱が激増します。マクロ温度 $T$ は `2897.05` から **`16264.61`** へと急上昇します。自由エネルギー $F$ は `132117.82` から **`-387283.36`** へと減少します。
  * **てんかん（Sample 9）:** 側頭葉（`03_Temporal_Lobe`）を起点とする異常なサイン波が全脳を強制同調させます。スペクトル半径は **`1.00`** に飽和します。PCA説明比率（PC1）が `37.5%` 付近で固定されます。この過同期を、物理特性で看破します。
  * **結論:** 「架空仕訳の自己還流」「交差点での車両デッドロック」「株式の対当取引」「脳波のてんかんバースト」は同型の病態です。エネルギーが局所閉回路に拘束されます。外部への代謝が阻害されます。システムは機能停止します。

### 🟡 3. 局所的・一時的不整合病態 (Localized Transient Mismatch)

* **対象:** [Sample 3 (入力ミス)](./Sample_3_Unbalanced_Mistake/README.md)
* **共通の物理シグニチャ:** **一時的な情報幾何学スパイク（KL Drift）、および自己治癒能力（弾性）**
* **機序のクロス検証:**
  * **仕訳の片面入力ミス（Sample 3）:** 売掛金の回収仕訳において、貸借の一方のみが入力されました。その結果、該当タイムステップ（`2020-02`）にマクロ保存残差が **`906.29`**（累積ズレ **`$1,412.88`**）発生しました。一時的にトポロジー剛性が歪みます。3D KL Drift プロットで **`20.68`** の巨大な針状スパイクが立ちました。
  * **回復 of プロセス:** システムは閉鎖的な還流を形成していません。次のタイムステップでミスが修正されると、KL Drift は即座にゼロへ復元しました。
  * **結論:** システムに弾性が残されていれば、一時的な衝撃が発生しても、元の平穏なリミットサイクルへ自律復元します。

### 🟢 4. 健全定常状態 (Healthy Steady-state)

* **対象:** [Sample 0 (正常対流)](./Sample_0_Healthy/README.md), [Sample 6 (株券流体平衡)](./Sample_6_Market_Stock_Flow/README.md), [Sample 7 (現金流体平衡)](./Sample_7_Market_Cash_Flow/README.md)
* **共通の物理シグニチャ:** **保存残差のゼロ、および流体安定性（安定限界内での定常対流）**
* **機序の検証:**
  * **正常循環 (Sample 0):** 還流閉路（$\rho = 0.00$）も質量リーク（残差 = `0.00`）もありません。各セクターが有機的に接続します。自由エネルギー $F$ は健全に成長します。季節変動により Z-Score が最大 **`4.90`** まで上昇していますが、物理保存則に不整合がないため「季節性の偽陽性」としてトリアージ（棄却）されます。
  * **市場流体 (Sample 6, 7):** 株式および現金が保存されたクローズド市場ネットワークにおいて、健全な定常対流が行われている状態です。還流自体は閉鎖強連結の数学的帰結（スペクトル半径 $\rho = 1.00$）です。しかし、摩擦や歪みは安定限界内に収まります。不整合残差は完全に `0.00` です。
