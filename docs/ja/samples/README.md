## 🤖 AI自動メタ診断における「モデル汚染」と「偽陽性トリアージ」

*   **茹でガエル現象（モデル汚染）の超克:**
    統計モデル（Z-Score）や機械学習モデルは、不正やアノマリー活動が長期間継続すると、それを「新しい日常（正常ベースライン）」として学習し、時間の経過とともに警告（Z-Scoreの針）を平坦化（沈黙）させてしまいます。TLUは、過去の履歴に依存しない「質量保存則（キルヒホッフ残差）」や「スペクトル半径（安定性）」という**物理的不変量**を優先することで、モデル汚染を看破します。
*   **統計的偽陽性の物理的トリアージ:**

*   **第三者物理原本との連結（反証可能性）:**
    レポートに記載されたすべての「反証条件（Falsifiability）」は、システム内部のデータを書き換えるような自己参照的な手段を排除し、必ず**データ境界の外側にある客観的物理証拠**（銀行通帳原本、出荷伝票原本、臨床脳波生データなど）と連結されています。

### [Sample 9: 過同期性脳機能障害（てんかん発作）](./Sample_9_fMRI_Seizure/README.md)
*   **物理特徴:** 側頭葉（`03_Temporal_Lobe`）起点のサイン波が全脳を強制同調。スペクトル半径 **`1.0000`**。PC1説明比率は `37.5%` 前後で変化しない（PCAの死角）。
*   **3D立体挙動:** 3D KL Drift プロットにおいて、発信源である側頭葉のドリフトが `0.0000` に留まるのに対し、周囲の受信領域（`00_Motor_Cortex` の `0.2333` など）の座標軸にのみ、**「同期に引きずり込まれた情報の歪みの壁」**がそびえ立ち、非対称な支配構造を証明します。

## ⚕️ 最適制御理論（LQR）による動的治療アプローチ

TLUは単に病的アノマリーを検知するだけでなく、制御工学における「最適線形レギュレータ（LQR）」を用いて、システムを再び健康な定常状態へ引き戻すための**「ツボ（介入ポイントと制御パルス）」**を算出します。

*   **金融・不正会計への介入:**
    LQRが算出した感度（Sensitivity Matrix）に従い、還流経路のハブとなっている売掛金口座への「仕訳バリデーション（粘性の追加）」や「相手方勘定の強制一時凍結（動的ダンピング）」を適用し、スペクトル半径を臨界値未満（$\rho < 0.8$）へ強制減衰させます。
*   **都市交通への介入:**
    渋滞のボトルネックとなる特定の交差点（経穴）の信号制御タイミングに「動的オフセット（位相変化）」を挿入し、車両の自律的な分散流動性を引き出します。
*   **生体（脳 fMRI）への介入:**
    脳梗塞（Sample 8）に対しては LQR 感度の最大経路に沿った tPA 等による物理開通を、てんかん（Sample 9）に対しては側頭葉焦点へ向けて LQR フィードバックパルス（経頭蓋磁気刺激 TMS）による「逆位相ノイズ」を照射し、機能的過同期の病的アトラクターを破壊します。
