## 🧠 病態分類別の比較検証・機序分析 (Pathological Cross-Verification)

TLUの最大の数理的ブレイクスルーは、**「ドメインの壁を超え、全く異なる事象が、物理方程式の上で同一の病理署名（シグネチャ）として解読される」**ことを実証した点にあります。以下に、物理モデルが分類した4つの病態グループの共通機序を検証します。

### 🔴 1. 質量欠損・虚血病態 (Mass Leak / Ischemia)

* **対象:** [Sample 2 (資金横領)](./Sample_2_Embezzlement_Leak/README.md), [Sample 8 (脳梗塞)](./Sample_8_fMRI_Stroke/README.md)
* **共通の物理シグニチャ:** **キルヒホッフ保存則の不整合、およびトポロジー剛性のフリーズ（Rigid Lock）**
* **機序のクロス検証:**
  * **金融（Sample 2）:** 売掛金の回収時に現預金へ格納されず、ダミーノード `UNKNOWN_LEAK` を経由して系外へ資金が吸い出されます。この結果、マクロ保存残差（`conservation_residual`）が最大 **`364.53`** 発生し、累計で **`$1,353.48`** の質量（資金）が失われました。アクティブな資金（流動性）が喪失した結果、勘定間の結合剛性が極限まで凝固し、後半のわずかな取引変動に対して10億（`1e9`）スケールの壊滅的な共振（ノッキング）を引き起こします。
  * **生体脳（Sample 8）:** TR=150 (`t=30`) 以降、運動野（`Motor_Cortex`）への血液（BOLD信号の質量）供給が 95% 遮断され、局所的に強烈な「虚血状態」となります。この質量の急減により、運動野周辺の機能的結合剛性（Stiffness）が異常凝固する「Rigid Lock」を引き起こし、運動野のエントロピーが崖のように垂直落下します。
  * **結論:** 企業からお金が盗まれる現象と、脳の血管が詰まって壊死する現象は、**「ネットワークから活動質量が失われ、サスペンション（弾性）が消滅して構造が硬直化する」**という物理方程式において同型の病態です。

### ⚖️ 2. 過同期・還流病態 (Hyper-synchronization / Recirculation)

* **対象:** [Sample 1 (循環取引)](./Sample_1_Wash_Trade/README.md), [Sample 5 (京都交通渋滞)](./Sample_5_Kyoto_Traffic/README.md), [Sample 6 (市場二部グラフ)](./Sample_6_Market_Bipartite_Weekly/README.md), [Sample 7 (市場資金移動)](./Sample_7_Market_Users_Weekly/README.md), [Sample 9 (てんかん発作)](./Sample_9_fMRI_Seizure/README.md)
* **共通の物理シグニチャ:** **スペクトル半径（$\rho$）の上限飽和、および自由エネルギーの摩擦消費（エントロピー損失）**
* **機序のクロス検証:**
  * **循環仕訳（Sample 1）:** 実体のない往復取引により、スペクトル半径が警戒域の **`0.75`** まで急上昇。内部活動量（内部エネルギー $U$）は見かけ上右肩上がりに成長しているにもかかわらず、そのエネルギーは往復の摩擦熱（エントロピー $T \times S$）として浪費され、実質的なスタミナである自由エネルギー $F = U - TS$ を損ないます。
  * **都市交通（Sample 5）:** 流入車両が限界を超え、四条烏丸周辺の容量制限（ボトルネック）によりスペクトル半径が境界上限値である **`1.00`** に飽和（デッドロック）。マクロエントロピーは `38.70` へと低下しますが、速度のばらつきによる摩擦熱が激増し、マクロ温度 $T$ は `457.24` から **`547.06`** へと急上昇。自由エネルギーは `2,481,482` から **`2,478,826`** へと減少しました。
  * **相場操縦（Sample 6, 7）:** ボット間または共謀口座（`USR_003` ⇄ `USR_004`）間でミリ秒単位のキャッチボール取引が発生し、スペクトル半径は限界値の **`1.00`** に飽和。Sample 7 では、共謀による流動性偏在を示す自由エネルギー歪度（Skewness）が **`-2.72`** へと崩壊します。
  * **てんかん（Sample 9）:** 側頭葉（`03_Temporal_Lobe`）を起点とする異常なサイン波が全脳を強制同調させ、スペクトル半径は **`1.00`** に飽和。PCA説明比率（PC1）が `37.5%` 付近で全く変動しないという統計の死角を突く過同期を、物理特性で看破します。
  * **結論:** 「架空仕訳の自己還流」「交差点での車両デッドロック」「株式の対当取引」「脳波のてんかんバースト」は、すべて**「エネルギーが局所閉回路に拘束され、外部への有益な価値伝達や代謝を阻害してシステムを熱的死（機能停止）に追い込む」**という還流病態のバリエーションです。

### 🟡 3. 局所的・一時的不整合病態 (Localized Transient Mismatch)

* **対象:** [Sample 3 (入力ミス)](./Sample_3_Unbalanced_Mistake/README.md)
* **共通の物理シグニチャ:** **一時的な情報幾何学スパイク（KL Drift）、および強靭な「自己治癒能力（弾性）」**
* **機序のクロス検証:**
  * **仕訳の片面入力ミス（Sample 3）:** 売掛金の回収仕訳において、貸借の一方のみが入力されたことで、該当タイムステップ（`2020-02`）にマクロ保存残差が **`906.29`**（累積ズレ **`$1,412.88`**）発生。一時的にトポロジー剛性が歪み、3D KL Drift プロットで **`20.68`** の巨大な針状スパイクがそびえ立ちました。
  * **回復のプロセス:** システムが閉鎖的な還流を形成していないため、次のタイムステップでミスが修正されると、KL Drift は即座にゼロベースラインへと沈み込み、平坦な野原へと復元しました。
  * **結論:** システムに弾性（サスペンション）が残されていれば、一時的な衝撃（入力ミス、あるいは交通の一時的な合流混雑など）が発生しても、自己組織化によって元の平穏なリミットサイクルへ自律復元（自己治癒）します。

### 🟢 4. 健全定常状態 (Healthy Steady-state)

* **対象:** [Sample 0 (正常対流)](./Sample_0_Healthy/README.md)
* **共通の物理シグニチャ:** **保存残差のゼロ、スペクトル半径 `0.00`、自由エネルギーの健全な右肩上がり成長**
* **機序の検証:**

  * 商取引の季節変動により Z-Score が 7月に最大 **`4.90`** まで上昇していますが、トポロジーや物理保存則の指標が健全であるため、統計モデルが起こした「季節性の偽陽性」として正しくトリアージ（棄却）されます。
