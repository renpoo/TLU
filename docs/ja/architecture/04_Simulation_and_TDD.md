# 04. シミュレーションとテスト駆動開発 (Simulation and TDD)

> **"オーケストレーションされたカオス（混沌）に直面したことのない数学モデルは、単なる理論的おもちゃに過ぎない。真実は、厳密で敵対的なシミュレーションを通じてのみ証明される。"**

Tensor-Link Utility (TLU) は絶対的な数学法則の上に構築された処理系です。しかし、これらの法則を現実世界のビジネス環境で信頼するためには、継続的にテストされなければなりません。

カテゴリ **04（シミュレーション）** は、複雑なネットワークベースの「人工現実」を合成し、コア解析フィルターを厳密に検証するためのものです。

---

## 1. 人工的な合成の必要性

現実の乱雑なビジネスデータを見ているだけでは、アルゴリズムが正しいかどうかを知ることは困難です。フィルターが機能することを証明するためには、数学的に「真の答え」がすでに分かっている入力ストリーム（事前集約されたデータ）を合成し、それをパイプラインに流し込み、突合しなければなりません。

## 2. 生成モード

### ベースライン（帰無仮説）モード
* **メカニズム:** 純粋で均一なホワイトノイズのストリームを生成します。
* **目的:** このモードでは、TLU は剛性をゼロとし、異常フラグ（アノマリー）を「絶対に」トリガーしてはなりません。根本的な構造が存在しない場合にシステムが沈黙を保つ能力を検証します。

### リアルビジネス（因果）モード
* **メカニズム:** 実際の企業ネットワークの乱雑な物理学を模倣します。
* **特徴:** ハブ・ノードの作成、パレート分布、および 1/fゆらぎを利用した景気循環の模倣。

## 3. 決定論的アノマリーの注入（「毒」のレシピ）

TLU が帳簿の改竄、隠蔽工作、または相転移を捕捉できることを証明するために、シミュレーターはデータストリームに決定論的な「毒」を注入します。

* **ミクロ・フォレンジック（Z-Score）のトリガー:** シミュレーターは、特定のノードに巨大なスパイクを強制的に上書きします。
* **KLダイバージェンス・ドリフトのトリガー:** ボリュームを一定に保ちつつ、送信先を密かに変更します。これは「横領・資金着服」や「静かな資金流用」を合成するものです。
* **マクロ・フォレンジック（保存則のリーク）のトリガー:** 対応する流出を伴わない流入を注入し、システムの質量の喪失（資金の消失）を検知させます。
* **発散リスクのトリガー（循環取引）:** 意図的に閉ループ（循環取引）を形成するように設計された取引を注入し、システム安定性（スペクトル半径）が即座にフラグを立てることを確認します。

## 4. CI/CD との統合

シミュレーターは決定論的に動作するため、TLU の自動テストスイートに直接統合されています。コアな数学関数が更新されるたびに、パイプラインにはこれらの合成されたアノマリー・データが砲撃のように流し込まれます。
