# 03. ビジュアライザーとテーマエンジン (Visualizer and Theme Engine)

> **"数学は真実を発見し、可視化はそれを否定できないものにする。しかし、歪んだレンズは最も純粋な方程式でさえも歪曲してしまう。"**

TLU パイプラインの第3フェーズ（プレゼンテーション）は、認知負荷のオフロードを担当します。純粋な処理系によって生成された高密度な CSV ストリームを、高精度の視覚的アーティファクトへと翻訳し、現実世界との**突合**を可能にします。

---

## 1. 最優先指令：ビューでの計算禁止

Visualizer 層は、いかなる分析的な計算も実行することを厳格に禁じられています。

* Z-Scoreを計算することはなく、平均値を算出することもありません。
* その唯一の責任は **レンダリング** です。事前に計算された数値を視覚的な次元に射影することです。この厳格な分離により、視覚的な出力が数学的コアの完全な鏡であることが保証されます。

## 2. フェイルファスト・テーマエンジン

暗黙のうちに適用されたデフォルトカラーによってチャートがデータを誤って表現すれば、その結果としてのビジネス上の決定（比較衡量）は破滅的なものになる可能性があります。

これを防ぐため、TLU は **フェイルファスト・テーマエンジン** を採用しています。
特定のノードに割り当てられた意味論的な色が欠落している場合、デフォルトにフォールバックすることなく即座に停止します。嘘をつくダッシュボードを出力するくらいなら、壊れたパイプラインの方がマシだからです。

## 3. 意味論的カラーマッピング：ネットワーク・トポロジーとストレス

TLUの視覚的哲学の最たる例が、**位相幾何学的ストレス**ビジュアライザーです。組織のアノマリーは血管を流れる毒のようにネットワークを流れていきます。

### ノードのレンダリング（純フラックス）
* **指標:** 絶対的な流入量 vs. 流出量。
* **意味:** ノードの現在の質量と極性。エネルギーを蓄積しているのか、それとも出血しているのか。

### エッジのレンダリング（アノマリーのストレス）
* **指標:** 接続を通過するフラックスのZ-Score。
* **意味:** Z-Scoreが閾値を超えて上昇すると、エッジは明るい黄色へと変化します。これにより人間は、隠された改竄ルートや破裂リスクを瞬時に発見することができます。

### 時系列の伝播（脈動と相転移）
各タイムステップごとにフレームを生成することで、組織の「脈動」やマクロな**相転移**を観察することができます。あるノードへのショックは、下流への順運動学として視覚的に追跡可能です。

## 4. ユニバーサルな 3D 曲面翻訳

TLUは 3D 多様体レンダリングに大きく依存しています。
* **X/Y 軸:** 空間トポロジーまたは時間を表します。
* **Z 軸 (高さ):** 幾何学的歪み（曲率）、ひずみエネルギー、または速度を表します。

これらの厳格な視覚エンジンを通じて、TLU はドメインの複雑性が絶対的な透明性へと射影されることを保証します。
