# 06. ダミーデータ生成器 (Dummy Data Generators)

監査システムの正確性を検証するためには、様々な不正や異常を意図的に含ませたテストデータが必要です。TLUには、現実世界の複雑な取引ネットワークをシミュレートし、システムの異常検知能力をテストするための高度なデータ生成プログラムが2種類組み込まれています。

---

## 1. 会計仕訳シミュレーター（財務ネットワークの生成）

このプログラムは、企業において複数年にわたって発生する日々の会計仕訳データを自動生成します。

### 現実的な取引環境の再現
* **取引の偏り（ハブの形成）:** 現金や買掛金といった特定の口座に取引が集中する、現実の企業活動によく見られるネットワーク構造を再現します。
* **時間的遅延（摩擦）の再現:** 「売上が発生してから、後日回収される」といった取引間のタイムラグをシミュレートし、システムに「時間の流れ（摩擦）」を認識させます。
* **景気循環の模倣:** 取引ボリュームに自然なゆらぎを持たせることで、単調なデータではなく、現実の景気循環に近いノイズを含んだデータを生成します。

### 不正データ（異常）の意図的な混入
TLUの検知機能をテストするため、生成データに以下のような特定の「異常」を注入できます：

1. **極端な支出（Z-Spike）:** 特定の日に1回限りの巨大な取引を発生させます。
2. **資金の消失（Leak）:** 借方と貸方のバランスが取れていない「資金の外部流出（横領など）」を発生させます。
3. **資金の流用（Drift）:** 全体の支出額は変えずに、支払先だけを徐々に別の口座へ変更させる、目立たない資金流用を模倣します。
4. **仕訳の不一致（Unbalanced Mistake）:** 単純な入力ミスや、借方・貸方が一致しない改ざん仕訳を発生させます。
5. **循環取引（Wash Trading）:** 複数の口座間で資金がループし続ける架空取引を注入し、システムの異常膨張（スペクトル半径の上昇）として検知できるかをテストします。

---

## 2. 空間ネットワーク・シミュレーター（対照実験用）

財務データのシミュレーターとは別に、物理的なモノの移動（物流や交通）をシミュレートするプログラムも用意されています（京都の街路網モデルを採用）。

### 特徴と目的
* **空間的な制約:** 資金のように自由に口座間を移動するのではなく、「物理的に隣り合った場所にしか移動できない」という制約を持たせたデータを生成します。
* **渋滞のシミュレーション:** 物理的な渋滞がネットワーク全体にどのような影響を与えるかをテストします。

このシミュレーターは、TLUの採用している「物理数学モデル」が、会計データだけでなく、物流などの物理的なネットワークの異常検知にも全く同じように適用可能であることを証明するための対照実験として機能します。
