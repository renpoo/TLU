# 06. ダミー・データ・ジェネレーター (Dummy Data Generators)

> **"診断エンジンの真価は、それが検出できるアノマリーの質によってのみ決まる。"**

TLU の分析力を検証するために、システムには2つの高度なダミー・データ・ジェネレーターが組み込まれています。これらは複雑な現実世界のダイナミクスをシミュレートし、TLU処理系の検出機能の限界をテストするために「数学的に正確なアノマリー（毒）」を注入するように設計されています。

---

## 1. ダミー仕訳ジェネレーター（財務・組織のフロー）

このジェネレーターは、企業の複数年にわたる日々の会計仕訳をシミュレートします。

### 自然なベースライン・ダイナミクス
* **スケールフリー・ネットワーク・トポロジー:** 支払債務（買掛金）や現金などの少数のノードが巨大なハブとして機能します。
* **因果イベントキュー（粘性・摩擦）:** 今日の売上債権の発生は、将来の回収イベントをスケジュールします。この時間的遅延が、空間の「粘性」を生み出します。
* **ピンクノイズ（1/fゆらぎ）:** 取引ボリュームはフラクタル・ノイズによって変調され、自然な景気循環を模倣します。

### アノマリー注入メカニズム（改竄のシミュレーション）
TLUのフォレンジック・フィルターをトリガーするために、特定のアノマリーを注入します：

1. **Z-Spike（外れ値の支出）:** 巨大な1回限りの取引。
2. **Leak（横領・資金着服）:** バランスする入力なしに、資金が外部へ移動（消失）します。保存則のリーク検出器によって捕捉されます。
3. **Drift（静かなサプライヤーの切り替え）:** 総支出は正常なままですが、送信先がシフトします。これは横領を隠蔽する手口であり、KLドリフトで捕捉されます。
4. **Unbalanced Mistake（帳簿改竄の綻び）:** 借方と貸方が一致しない取引。
5. **Wash Trading（循環取引）:** 意図的に閉ループを形成するように設計された取引。これは組織の自然な構造を破壊し、**スペクトル半径** フィルターによって即座にフラグが立てられます。

---

## 2. ダミー・トラフィック・ジェネレーター（物理的・物流のフロー）

仕訳ジェネレーターが会計に焦点を当てているのに対し、このジェネレーターは京都の街路網モデルに基づいて、物理的なオブジェクトのフローをシミュレートします。

### 特徴
* **空間グリッド・ネットワーク:** フローは物理的に隣接するノードに制限されます。
* **渋滞シミュレーション:** 剛性や、多様体の次元性（交通渋滞がネットワークの有効ランクをどのように崩壊させるか、マクロな相転移）のテストを可能にします。

このジェネレーターは、TLUの数学的抽象化がドメインに依存せず、財務元帳と全く同様に物理的なロジスティクスにも適用できることを証明します。
