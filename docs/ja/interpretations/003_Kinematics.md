# 003. 運動学 (Kinematics)

運動学（Kinematics）は、ビジネス上の意思決定による「波及効果（Ripple effects）」をシミュレートすることを可能にします。ある口座に現金を注入したときに、組織の残りの部分が構造的にどのように動くかを予測することができます。

---

### 1. 3D 運動学: 順運動学シミュレーション (FK) (`003_1_1__3d_kinematics_fk.png`)

![003_1_1__3d_kinematics_fk](../../readme_plots/003_1_1__3d_kinematics_fk.png)

* **📊 視覚的構造**: 相互接続されたポイントのネットワークを示す3D空間プロット。
* **📐 物理理論**: 順運動学シミュレーション（順問題）。もし既知の力を適用した場合、歴史的な剛性に基づいて、残りの口座は物理的にどのように動き、調整されるか？
* **🚨 アノマリー検出 (Anomaly Detection)**:
  * 営業への現金注入が、全く無関係の口座に、予期せぬほど大規模で激しい変位を引き起こす場合。
* **💼 ビジネスへの翻訳**: **介入のシミュレーション**。ビジネス上の意思決定の「爆風の範囲」を視覚的に検証するためにこれを使用します。マーケティング予算の増加が買掛金ノードを不安定化させる場合、組織の内部プロセスはその成長を処理するには脆すぎます。

### 2. 3D 運動学: 逆運動学 (IK) (`003_1_2__3d_kinematics_ik.png`)

![003_1_2__3d_kinematics_ik](../../readme_plots/003_1_2__3d_kinematics_ik.png)

* **📊 視覚的構造**: ターゲットの目的地から「逆算」して機能します。
* **📐 物理理論**: 逆運動学（Inverse Kinematics）。組織を特定の財務状態に到達させたい場合、構造的なひずみ（粘性・摩擦）を最小限に抑えながらそこに到達するためには、「正確にどのような力」を適用しなければならないか？
* **🚨 アノマリー検出 (Anomaly Detection)**:
  * ソルバーが収束しない、または結果として得られたベクトルが天文学的に巨大になる。
* **💼 ビジネスへの翻訳**: **KPI に対する現実性のチェック**。もし必要な力が不可能なほど巨大である場合、経営陣の目標は空想であり、実行を試みれば組織の構造を破壊することを数学的に証明しています。
* **💡 具体例（サンプル・データより）**:
  * **Sample_5（京都交通ネットワーク制御）**: 資金フローだけでなく、物流網や交通網にも運動学は適用されます。四条河原町などの「大渋滞（異常に高い剛性と摩擦を持つ交差点）」が発生している時、逆運動学（IK）ソルバーは、目的地に到達するための「最も抵抗（Strain Energy）の少ない迂回ルート」を自動的に計算し提案します。もし全ルートが渋滞（極めて高い剛性）で塞がれていて要求された目標到達時間に到達できない場合、IKソルバーは巨大なベクトルを発散させるか収束に失敗し、「現在のリソースでは物理的に不可能である（KPIの非現実性）」ことを数学的に証明します。
