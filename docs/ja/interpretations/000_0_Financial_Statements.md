# 000_0. 財務諸表とベースライン (Financial Statements & Baseline)

## 🔬 結論：高度な解析の前に「土台（基本原則）」が崩れていないか

本ドキュメントでは、TLUが高度な物理数学を用いた解析（Phase 2以降）に入る前に提示する、標準的なB/S（貸借対照表）およびP/L（損益計算書）のダッシュボードについて解説します。
ここでの結論はシンプルです。**「システムが提示する『異常のサイン』を疑う前に、そもそも生のデータが基本的な会計方程式（資産 ＝ 負債 ＋ 資本）を守っているか、あるいは利益の基盤が致命的に崩壊していないか」**を検証します。

これらの図は、組織の現在地を把握するための「絶対的な基準点（ベースライン）」として機能します。

---

## 組織の基礎体力の可視化

### 貸借対照表（B/S）ブロックチャートと基本原則

![Sample 0 B/S](../../../../samples/Sample_0_Healthy/readme_plots/000_0_1__BS_Block_Total.png)

* **📊 視覚的構造**: 伝統的な左右対比型の積み上げ棒グラフ。
* **🚨 異常の検知（マクロ・ミクロ）**:
  * **[マクロ] 左右の不一致:** もし左右の棒グラフの高さが完全に一致していない場合、高度なフォレンジックを行うまでもありません。元となる仕訳データそのものが壊れています（借方・貸方の不一致、入力エラー、システムの致命的なバグなど）。
  * **[マクロ] 資本ブロックの沈み込み:** 利益剰余金（資本ブロックの一部）が「ゼロの線」より下へ伸びている場合、その企業は構造的に赤字（純損失）を累積し続けており、債務超過の危険水域にあります。

## 利益の浸食とモメンタムの確認

B/Sで全体的な健全性を確認した後は、P/Lを通じて「日々のビジネスがどのように利益を生み出し、どこで削り取られているか」を特定します。

### 損益計算書（P/L）ウォーターフォール

![Sample 0 P/L Waterfall](../../../../samples/Sample_0_Healthy/readme_plots/000_0_1__PL_Waterfall_Total.png)

* **📊 視覚的構造**: 収益から各種費用が差し引かれ、最終的な純利益に至るまでの流れを示す滝（カスケード）状のステップチャート。
* **🚨 異常の検知**: 他の費用項目と比べて、不釣り合いに巨大な「赤い費用ブロック（特定の経費のスパイク）」がないかを探します。突如として特定の月に巨大な赤いブロックが現れた場合、その科目に絞った即時の監査（突発的な無駄遣いや不正の調査）が必要です。

### 損益計算書（P/L）トレンド

![Sample 0 P/L Trend](../../../../samples/Sample_0_Healthy/readme_plots/000_0_1__PL_Trend.png)

* **📊 視覚的構造**: 時系列の棒グラフ（収益・費用）および折れ線グラフ（純利益）。
* **🚨 異常の検知**: 緑の収益バー（売上）が横ばい、あるいは低下している時期に、赤い費用バー（経費）だけが突如として跳ね上がっている（説明のつかないスパイク）箇所がないかを探します。これは、組織が柔軟性を失い、構造的な固定費の重圧に苦しんでいるサインです。

## 🔬 反証可能性とモデルの限界（実務への適用）

財務諸表のベースライン可視化は、「現在の帳簿上の数字がどうなっているか」という**集計結果（事実）**をありのままに提示します。
しかし、このフェーズでは「その数字が真実であるかどうか」は断定できません。

たとえば、B/Sの左右が完璧に一致し、P/Lの利益が右肩上がりであっても、それが**「Sample 1 のように、循環取引によって架空の売上が捏造された結果」**である可能性は排除できません。
だからこそ、このベースラインの確認を終えた後、私たちは Phase 2 以降の「熱力学」「情報幾何学」「制御理論」という物理学のレンズを用いて、数字の裏に隠された「見えない異常（質量の欠落やエントロピーの増大）」を暴き出すプロセスへと深く潜っていくのです。
