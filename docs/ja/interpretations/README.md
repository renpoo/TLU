# TLU ダッシュボード解釈ガイド (Graph Interpretation Guide)

TLUは、組織の構造的な健康状態や隠れた不正を特定するために、50種類以上の高度なダッシュボード（可視化グラフ）を生成します。

本ディレクトリは、監査役や経理担当者などのエンドユーザーが、生成されたグラフを見て**「どこに異常があるのか」「それが実務上何を意味するのか」**を判断するための公式マニュアルです。

---

## 3D Surface グラフの「読み方」の基本フレームワーク

TLUが多用する「3D Surface グラフ」は、**「全体（マクロ）」**と**「局所（ミクロ）」**の2つの視点を組み合わせて読むことで、真のインサイトを発見できるよう設計されています。

### 1. マクロな視点：地形（波打ち）を読む
* **見方:** グラフ全体のなだらかな起伏やトレンドを俯瞰します。
* **分かること:** 「期末に向かって全体的に資金の滞留（波の隆起）が激しくなっている」といった、組織全体の構造的な変化や、景気循環などの正常なトレンドを把握します。

### 2. ミクロな視点：針（スパイク）を読む
* **見方:** なだらかな地形から突如として突き出た「鋭い針（スパイク）」や「深い穴」を探します。
* **分かること:** 「この特定の日、特定の口座にだけ、通常のトレンドから外れた巨大な異常値が発生している」といった、横領や架空計上、あるいは極端な入力ミスなどの単発的な異常を特定します。

### 3. 視点の組み合わせによる不正の特定
* **「地形は平穏だが、鋭いスパイクがある」** ＝ 隠蔽された単発の不正・エラーの可能性が高い。
* **「スパイクはないが、地形が不自然に右肩上がりになっている」** ＝ 循環取引や粉飾決算など、組織全体を使った持続的・構造的な売上の水増しの可能性が高い。

## ガイドの構成（カテゴリ別）

各ガイドでは、深遠な数学的公式ではなく、監査実務に直結する**「視覚的な異常の見つけ方」**を解説します。

* **[000_0: 財務諸表](000_0_Financial_Statements.md)**: 物理解析に入る前の、標準的な B/S（貸借対照表）と P/L（損益計算書）の推移の読み方。
* **[000: 古典力学と剛性](000_Classical_Mechanics_and_Stiffness.md)**: 資金規模（質量）や回収遅延（粘性）の3D空間の読み方。
* **[001: 熱力学とエントロピー](001_Thermodynamics_and_Entropy.md)**: 組織の疲弊度（エントロピー）と資金枯渇（自由エネルギー）の読み方。
* **[002: 情報幾何学とフォレンジック](002_InfoGeometry_and_Forensics.md)**: 巧妙な不正（横領・改ざん）を検知するZ-ScoreとKLドリフトの読み方。
* **[003: 応用運動学](003_Kinematics.md)**: 資金投入時の波及効果シミュレーションの読み方。
* **[004: 制御工学と安定性](004_ControlTheory_and_Stability.md)**: 循環取引を検知するスペクトル半径の読み方。
* **[005: 信号とノイズ](005_Signals_and_Noise.md)**: 帳簿の捏造や自動ボットの介入を検知する周波数解析の読み方。

> [!NOTE]
> 監査人や税理士がこれらすべてのグラフの特徴を暗記する必要はありません。TLUに搭載された **AI メタ診断エンジン** が、事前に異常を検知してレポート（ビジネス・ナラティブ）に翻訳します。本ガイドは、AIが指摘した異常箇所を**「人間が自分の目で見て最終確認（突合）するため」**に使用してください。
