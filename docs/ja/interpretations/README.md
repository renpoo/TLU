# TLU 可視化グラフ解釈ガイド (Graph Interpretation Guide)

TLUは、組織の構造的な健康状態や隠れた不正を特定するために、50種類以上の高度な可視化グラフを生成します。
本ガイドは、監査役や経理担当者などのエンドユーザーが、生成されたグラフを見て**「どこに異常があるのか」「それが実務上何を意味するのか」**を判断するための公式マニュアルです。

> [!IMPORTANT]
> **本ガイドの使い方：AIとの協働が前提です**
> 監査人や税理士がこれらすべてのグラフの特徴を暗記する必要はありません。TLUに搭載された **AI メタ診断エンジン** が、事前に生データを解析して異常を検知し、レポート（ビジネス・ナラティブ）に翻訳します。
> 本ガイドは、最初からグラフを睨みつけるためのものではなく、**「AIが指摘した異常箇所を、人間が自分の目で見て最終確認（突合）するためのロゼッタストーン」**として使用してください。

> [!NOTE]
> **裏返しの哲学：究極の「複式簿記」**
> なぜ物理学のグラフで不正が分かるのでしょうか？ それは、TLUが「エネルギー保存の法則」を監査に適用しているからです。これは、**複式簿記の「貸借一致の原則」を、高度な数学空間に拡張した究極の監査ロジック**です。1円の漏洩（横領）も、無から有を生み出す取引（循環取引）も、この物理法則（＝厳密な複式簿記）から逃れることはできません。

## 3D Surface グラフの「読み方」の基本フレームワーク

TLUが多用する「3D Surface グラフ」は、**「全体（マクロ）」**と **「局所（ミクロ）」** の2つの視点を組み合わせて読むことで、真のインサイトを発見できるよう設計されています。

### 1. マクロな視点：地形（波打ち）を読む

* **見方:** グラフ全体のなだらかな起伏やトレンドを俯瞰します。
* **分かること:** 「期末に向かって全体的に資金の滞留（波の隆起）が激しくなっている」といった、組織全体の構造的な変化や、景気循環などの正常なトレンドを把握します。

**【🟢 正常な地形の例（Sample 0）】**
![Macro Terrain](../../readme_plots/Sample_0_Healthy/002_2_2_2__micro_Z_Score_3d_surface.png)

### 2. ミクロな視点：針（スパイク）を読む

* **見方:** なだらかな地形から突如として突き出た「鋭い針（スパイク）」や「深い穴」を探します。
* **分かること:** 「この特定の日、特定の口座にだけ、通常のトレンドから外れた巨大な異常値が発生している」といった、横領や架空計上、あるいは極端な入力ミスなどの単発的な異常を特定します。

**【🔴 異常なスパイクの例（Sample 2: 横領）】**
![Micro Spike](../../readme_plots/Sample_2_Embezzlement_Leak/002_2_2_2__micro_Z_Score_3d_surface.png)

### 3. 視点の組み合わせによる不正の特定

* **「地形は平穏だが、鋭いスパイクがある」** ＝ 隠蔽された単発の不正・エラー（横領・入力ミスなど）の可能性が高い。
* **「スパイクはないが、地形全体が不自然に発散・暴走している」** ＝ 循環取引や粉飾決算など、組織全体を使った持続的・構造的な売上の水増しの可能性が高い。

## 監査ワークフローと詳細ガイド

AIからのレポートを受け取った後、以下のワークフローに従って各ドキュメントを参照し、視覚的な証拠を確認してください。深遠な数学的公式ではなく、監査実務に直結する**「視覚的な異常の見つけ方」**を解説しています。

### Step 1: 基礎確認（全体の健康診断）

物理解析に入る前の、標準的な財務指標の推移を確認します。

* **[000_0: 財務諸表](000_0_Financial_Statements.md)**: B/S（貸借対照表）と P/L（損益計算書）の基本的なトレンドの読み方。

### Step 2: マクロ監査（構造的な異常の特定）

組織全体を巻き込んだ、大規模な不正や機能不全（循環取引、資金の枯渇など）を監査します。

* **[004: 制御工学と安定性](004_ControlTheory_and_Stability.md)**: 循環取引や粉飾決算を検知する「スペクトル半径（システムの暴走）」の読み方。
* **[001: 熱力学とエントロピー](001_Thermodynamics_and_Entropy.md)**: 組織の疲弊度（エントロピー）と、慢性的な資金流出・枯渇（自由エネルギー）の読み方。
* **[000: 古典力学と剛性](000_Classical_Mechanics_and_Stiffness.md)**: 資金規模（質量）や回収遅延（粘性）の3D空間の読み方。

### Step 3: ミクロ監査（ピンポイントの犯人・原因特定）

マクロな異常を引き起こしている、あるいは単独で隠蔽されている「特定の口座・日時・行動」を特定します。

* **[002: 情報幾何学とフォレンジック](002_InfoGeometry_and_Forensics.md)**: 巧妙な不正（横領・改ざん）の正確な発生座標をピンポイントで刺し貫く Z-Score と KLドリフトの読み方。
* **[005: 信号とノイズ](005_Signals_and_Noise.md)**: 馴れ合い取引（シンジケート）や自動ボットによる「不自然なタイミングの完全同期（人工的な位相ドリフト）」を暴く周波数解析の読み方。
* **[003: 応用運動学](003_Kinematics.md)**: 「誰のどの行動がこの結果を引き起こしたか」という原因を逆算（逆運動学・IK）するフォレンジック・シミュレーションの読み方。
