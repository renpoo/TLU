# TLU 可視化グラフ解釈ガイド (Graph Interpretation Guide)

## 🔬 結論先行：物理法則が暴き出す「見えない異常の視覚的証拠」

TLUは、組織の構造的な健康状態や隠れた不正を特定するために、50種類以上の高度な可視化グラフを生成します。
本ガイドの結論は、**「どれほど巧妙に隠蔽された不正や複雑な病変であっても、物理法則（熱力学、運動学、トポロジー）のレンズを通せば、必ず『不自然な地形』や『異常なスパイク』として視覚化される」**ということです。

本ガイドは、監査役や経理担当者、インフラ管理者などのエンドユーザーが、生成されたグラフを見て**「どこに異常があるのか」「それが実務上何を意味するのか」**を判断するための公式マニュアルです。

> [!IMPORTANT]
> **本ガイドの使い方：AIとの協働が前提です**
> 専門家がこれらすべてのグラフの特徴や数式を暗記する必要はありません。TLUに搭載された **AI メタ診断エンジン** が、事前に生データを解析して異常を検知し、レポート（ビジネス・ナラティブ）に翻訳します。
> 本ガイドは、最初からグラフを睨みつけるためのものではなく、**「AIが指摘した異常箇所を、人間が自分の目で見て最終確認（突合）するためのロゼッタストーン」**として使用してください。

## 🎨 グラフ読解の基本：全体像から細部へのボトムアップ・アプローチ

絵画のデッサンでまず全体の構図を取り、そこから細部を描き込んでいくように、TLUのグラフも**「全体（マクロな地形）」**から**「局所（ミクロなスパイク）」**へと解像度を上げて読んでいきます。

### 1. マクロな視点：地形（波打ち）とトレンドを読む
* **見方:** グラフ全体のなだらかな起伏やトレンドを俯瞰します。
* **分かること:** 「期末に向かって全体的に資金の滞留（波の隆起）が激しくなっている」といった正常な季節変動や、「システム全体が徐々に熱力学的な死（摩擦熱の無限増大）に向かっている」といった構造的な変化を把握します。

**【🟢 正常な地形の例（Sample 0）】**
![Macro Terrain](../../../samples/Sample_0_Healthy/readme_plots/002_2_2_2__3d_micro_z_score_X.png)

### 2. ミクロな視点：異常な「針（スパイク）」や「断裂」を読む
* **見方:** なだらかな地形から突如として突き出た「鋭い針（スパイク）」や、強固な繋がりが突然消えた「断裂（空白）」を探します。
* **分かること:** 「この特定の日、特定の口座にだけ、通常のトレンドから外れた巨大な質量欠損が発生している」といった、横領や架空計上、ピンポイントの脳梗塞（血流遮断）などの単発的な異常を特定します。

**【🔴 異常なスパイクの例（Sample 2: 横領）】**
![Micro Spike](../../../samples/Sample_2_Embezzlement_Leak/readme_plots/002_2_2_2__3d_micro_z_score_X.png)

### 3. 視点の組み合わせによる不正の特定
* **「地形は平穏だが、鋭いスパイクがある」** ＝ 隠蔽された単発の不正・エラー（横領・入力ミスなど）の可能性が高い。
* **「スパイクはないが、地形全体が不自然に発散・暴走している」** ＝ 循環取引や粉飾決算など、組織全体を使った持続的・構造的なシステムの乗っ取りの可能性が高い。

## 📚 監査ワークフローと詳細解説へのリンク

AIからのレポートを受け取った後、以下のワークフローに従って各ドキュメントを参照し、視覚的な証拠を確認してください。深遠な数学的公式ではなく、実務に直結する**「視覚的な異常の見つけ方」**を解説しています。

### Step 1: 基礎確認（ベースラインの構築）
物理解析に入る前の、標準的な財務指標や総量の推移を確認します。
* **[000_0: 財務諸表とベースライン](000_0_Financial_Statements.md)**: 貸借一致の原則や、P/L（損益計算書）の基本的なトレンドの読み方。

### Step 2: マクロ監査（構造的な異常の特定）
組織全体を巻き込んだ、大規模な不正や機能不全（循環取引、資金の枯渇、交通網のデッドロックなど）を監査します。
* **[004: 制御工学と安定性解析](004_ControlTheory_and_Stability.md)**: 無限ループ（循環取引や相場操縦）を検知する「スペクトル半径（システムの暴走）」の読み方。
* **[001: 熱力学とエントロピー](001_Thermodynamics_and_Entropy.md)**: システムの死（Heat Death）や、慢性的な資金流出・活動余力の枯渇（自由エネルギー）の読み方。
* **[000: 古典力学および固体力学](000_Classical_Mechanics_and_Stiffness.md)**: ネットワークの弾力性と、崩壊（絶対硬直 / Rigid Lock）の読み方。

### Step 3: ミクロ監査（ピンポイントの犯人・原因特定）
マクロな異常を引き起こしている、あるいは単独で隠蔽されている「特定の口座・日時・行動」を特定します。
* **[002: 情報幾何学とフォレンジック](002_InfoGeometry_and_Forensics.md)**: 巧妙な不正（横領・改ざん）の正確な発生座標や、共謀グループをピンポイントで刺し貫く Z-Score と KL Drift の読み方。
* **[005: 波と信号解析による捏造検知](005_Signals_and_Noise.md)**: 人工的な介入（シンジケートや自動ボット）による「不自然なタイミングの完全同期」や「データ捏造（ホワイトノイズ化）」を暴く周波数解析の読み方。
* **[003: 応用運動学によるシミュレーション](003_Kinematics.md)**: 波及効果の予測（順運動学）と、「設定された経営目標が物理的に達成可能か（空想の目標ではないか）」を逆算する逆運動学（IK）の読み方。
