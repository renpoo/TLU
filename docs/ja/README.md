# 🔬 Tensor-Link Utility (TLU) 技術解説・診断ドキュメントポータル

Tensor-Link Utility (TLU) 技術ドキュメントポータルへお越しいただきありがとうございます。

TLU は、複式簿記、都市交通、金融市場、脳神経機能（fMRI）といった一見すると全く異なるドメインのネットワークデータを、**熱力学（Thermodynamics）**、**トポロジー（Topology）**、**運動学（Kinematics）**の物理法則に基づいて統一的に診断する**「普遍的物理エンジン (Universal Physics Engine)」**です。

本書は、システム内に潜む病的異常（不正会計、資金横領、渋滞、市場操縦、てんかん等）がどのようにエネルギーを浪費し、構造的硬直を招き、あるいは質量保存を破綻させてシステムを「熱的死」へと至らしめるかを、物理方程式と東洋医学（漢方・気血水・経絡理論）の臨床メタファーを交えて解き明かすための総合ガイダンスです。

## ⚕️ TLU 物理診断における東洋医学（漢方・気血水）のメタファー

TLUは、高次元の物理・数理パラメータを実務家（経営者、公認会計士、インフラ管理者、医師等）が直感的に理解できるよう、数千年の臨床実績を持つ東洋医学の語彙（漢方メタファー）に翻訳して出力する機能を備えています。

*   **質量 (Mass = 気血):** 口座資金や血流などのエネルギー総量。活動の源資。
*   **流量 (Flux = めぐり):** 仕訳取引額や車両の流れ。滞りなく循環することで健康を保つ。
*   **スペクトル半径 ($\rho \ge 1.0$ = 気血の逆流・厥逆):** 還流による暴走やデッドロック状態。
*   **質量保存残差 (Residual = 大出血):** 外部への資源流出・横領・出血。
*   **結合剛性 (Stiffness = 血栓・硬直):** 結合強度の異常硬化。しなやかさの喪失。
*   **LQR感度 (LQR Sensitivity = 経穴・ツボへの介入):** 最も効率よく治療できる急所。
