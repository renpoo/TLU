# 005. 信号処理と帳簿捏造の検知 (Signal Processing & Wave Mechanics)

カテゴリ **005** では、資金の出入りを「波（サイクル）」として分析します。
金額の大小だけでなく、取引の「タイミング」や「周期」を数学的に解析することで、人間の目には見えない自動プログラムによる不正介入や、人為的な「帳簿の捏造（改ざん）」をピンポイントで検知します。

---

## 1. 取引サイクルの分析（共振周波数） (005_1_1)

健全な企業活動には、給与の支払いや月末の締め日など、自然な「心拍（サイクル）」が存在します。TLUはデータからこの支配的な「周期（共振周波数）」を自動的に特定します。

### 不正な自動プログラムの検知
* 従来の「30日サイクル」が突如として崩れた場合、企業のビジネスモデルが根本的に変化した（または機能不全に陥った）ことを示します。
* 自然なサイクルとは異なる「不自然で機械的なピーク」が検出された場合、それは**自動化された資金着服スクリプト（ボット）**などが機械的に資金を引き出している明確な証拠となります。

## 2. 位相シフトと異常な同期 (005_1_2)

部署間の取引のタイミングの「ズレ（位相シフト）」と「同期度（コヒーレンス）」を評価します。

### 組織のメイン・エンジンとの連動性
TLUは組織全体を牽引している主要な流れ（第1主成分）を特定し、他のすべての部署がその流れとどれくらい連動しているかを計算します。

* **プロセスの崩壊（回収遅延など）:** 今まで主要な入金サイクルと連動していた部署が突如としてズレ始めた場合、その部署で巨大な業務の滞り（摩擦）が発生していることを警告します。
* **自動化スクリプトによる乗っ取り（異常な同期）:** 本来無関係であったはずの口座が、突然メイン口座と「不自然なほど完璧に同期」し始めた場合、**架空取引や循環取引**を行うスクリプトがその口座を強制的に操作し、売上を水増ししている可能性を強く示唆します。

## 3. 帳簿の捏造（データ改ざん）の検知 (005_2_1)

健全な組織のデータは、「ピンクノイズ（1/fゆらぎ）」と呼ばれる自然なフラクタル（自己相似）パターンを持ちます。

### 究極の「捏造・改ざん」検出器
人間（会計士や担当者）が、損失を隠蔽したり利益を水増ししたりするために、適当な偽の数値をでっち上げて帳簿に入力した場合、データの持つ自然なゆらぎは完全に破壊され、数学的に不自然なランダム性（ホワイトノイズ）へと転落します。

TLUは、フラクタル次元を解析することで「この数値の変動パターンは、自然な企業活動から生成されたものでは絶対にあり得ない」ということを数学的に証明し、人間による**帳簿の捏造・改ざん**を極めて高い精度で捕捉します。

## 4. 監査実務への応用
1. **機械的な不正:** 自動化されたプログラム（ボット）が定期的に資金を抜き取っていないか？
2. **架空取引の検知:** 無関係なはずの口座間で、不自然なほど完璧にタイミングが一致した取引（同期）が行われていないか？
3. **データの捏造:** 担当者が数値を適当にごまかして入力した（自然界には存在しないノイズを含む）痕跡はないか？
