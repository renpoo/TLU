# 株式取引の多次元分析: ユーザーの視点 (The User Perspective)

このドキュメントは、TLU処理系において **ユーザー（トレーダー、機関投資家、アルゴリズム）** を主要な実体として扱う際に適用される分析フレームワークの概要を説明します。トレーダーがアクターであり、株式は単に彼らが相互作用するための「乗り物」に過ぎません。

## 1. 運動学 (行動プロファイリング)
ユーザーの取引履歴を物理的な軌道としてマッピングすることで、彼らの真の性質と意図を分類することができます。
* **速度:** 注文実行の頻度。
* **加速度:** ユーザーがポジションを構築、または投売りする急速さ。加速度の突然のスパイクは、アグレッシブな成行注文やパニック売りを示しています。
* **粘性・摩擦:** ユーザーの「保有時間」や忍耐力を表します。
  * **低い粘性:** 摩擦のない環境で動作する高頻度取引アルゴリズム。
  * **高い粘性:** 機関投資家のようなバイ・アンド・ホールド投資家、または清算できない個人トレーダー。

## 2. 情報幾何学とフォレンジック (アノマリー検出)
ユーザーの取引パターンを確率の多様体として扱うことで、意図の逸脱を数学的に証明することができます。
* **KL ダイバージェンス (相転移):** 現在の取引戦略が歴史的なベースラインからどれほど乖離したか。突然のダイバージェンスは、アカウントの乗っ取りやインサイダー情報に基づく行動に先行します。
* **Z-Score 特異点:** 取引高や頻度が数学的に過去の分布を逸脱した「特定の瞬間」を特定し、異常な介入（例：「パンプ」を実行する扇動者）の正確なタイムスタンプをピンポイントで示します。

## 3. ネットワーク・トポロジーと位相力学 (影響力と共謀)
資金フロー・ネットワーク内におけるユーザーの「重力」を計算することで、彼らの真の市場支配力を暴くことができます。
* **固有ベクトル中心性:** 中心性の高いユーザーは、「最も接続されたノード」と取引しているため、市場の流動性に対して絶大な重力（引力）を持ちます。
* **位相シフトと同期 (共謀の改竄):** 協調的な攻撃を検出します。一見独立している複数のユーザーが、位相の遅れがゼロで完全に同期した取引パターンを示した場合、それは人工的な同期（改竄）を証明しています。これは自動化されたアルゴリズムの典型的な特徴です。
