# 株式取引の多次元分析ルール (Analysis Rules for Stock Market)

## 🔬 結論先行：金融市場の「見えざる手」を物理法則で暴き出す

本ディレクトリの最大の結論は、**「株式市場という超高速・高複雑性のエコシステムにおいて、表面上の『株価』や『出来高』を見るだけでは決して見抜けない、相場操縦アルゴリズム（HFT）や共謀グループの『物理的な質量と引力』を数学的に証明すること」**です。

TLU（Tensor-Link Utility）の物理エンジンを「株式取引」という特定のドメインに適用する際、どの物理変数をどのように解釈すべきかという、専門のフォレンジック・ルール（ロゼッタストーン）を定義しています。

---

## 📚 ドキュメント構成（マクロとミクロの視点）

市場の異常を検知するため、TLUは「市場全体（マクロ）」の物理的健康状態と、「個々のトレーダー（ミクロ）」の行動軌道という2つの視点から解析を行います。

### 1. マクロ解析（市場という有機体）
* **[株式取引の多次元分析: マーケットの視点](analysis_perspectives_market.md)**
  * **対象:** 市場全体の流動性、剛性、ボラティリティ。
  * **証明事項:** 循環取引（Wash Trading）による人為的な出来高の改竄（スペクトル半径 1.0）や、市場全体がショック吸収力（自由エネルギー）を失い、フラッシュ・クラッシュの危機に瀕しているかを証明します。

### 2. ミクロ解析（トレーダーという捕食者）
* **[株式取引の多次元分析: ユーザーの視点](analysis_perspectives_user.md)**
  * **対象:** 個々のトレーダーや機関投資家の取引履歴の軌道（運動学・情報幾何学）。
  * **証明事項:** そのユーザーが確率分布に従う人間か、それとも複数の口座を裏で一斉に操る「完全同期（位相差ゼロ）」の共謀アルゴリズム（シンジケート）かを証明します。

---

## ⚠️ 監査実務への適用（反証可能性）
本ルールセットは、特定の銘柄や口座群における「極めて異常な物理的・幾何学的な振る舞い」を断定します。しかし、それらが意図的な犯罪（相場操縦）であるかどうかの最終判断は、KYC（本人確認）や約定ログの直接調査といった、監査当局による追加の実査（Falsification）によってのみ確定されます。
